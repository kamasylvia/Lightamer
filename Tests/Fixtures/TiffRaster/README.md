# Tests/Fixtures/TiffRaster — the TIFF raster fixture matrix (M4-1-01 KD-2)

Generated by `Scripts/gen-tiff-fixtures.py` (idempotent — two runs are
byte-identical; regenerate with
`uv run --with tifffile --with numpy python3 Scripts/gen-tiff-fixtures.py`).
All images 64×64; the corner pixels carry the T6 bit-fidelity probe values
(0 / 0.18 / 0.5 / max in the first four columns of row 0) and the remaining
columns a per-channel ramp.

The embedded ICC profiles are synthesized by the generator itself (matrix-
shaper + Bradford chad + curv-carrier TRCs + the v4.4 cicp tag + mDCv +
mft2 A2B0 for the LUT forms); all TRCs ride `curv` carriers — never `para`
(the L053 macOS 27 misparse trap). No bytes were copied from any GPL
project.

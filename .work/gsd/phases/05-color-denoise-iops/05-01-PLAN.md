### T5 gen_fixtures 增加噪器 + 新 fixture 集 + 剖面钉参配方

- **action**
  1. 加噪器：`poisson_gaussian_noise(img, a, b, seed)`——`var = a·I + b`，`numpy.random.Generator(PCG64(seed))` 种子化，逐通道独立；输出 float32 EXR（走既有 uncompressed writer）。
  2. 加噪 fixture 集：canonical 子集（≥3 张）× 真实剖面档 2 档（ILCE-9M3 ISO 125 / ISO 1600，a/b 从 T3 产物取）→ ≥6 张加噪 EXR + manifest 登记种子与剖面参数。
  3. 新增三类 fixture：hue 全环 sweep 渐变（色相域覆盖，喂自研 parity——无 L017 风险）、delta 脉冲图（nlmeans/bilateral 核响应）、深阴影噪声 torture crop（SC#3 torture 直指，64-128px 级）。
  4. gen_fixtures 增剖面钉参 blob 配方族骨架：`denoiseprofile_params_blob`（v12 244B，含 x/y[6][7] 曲线 pack——**先过 dt `--d params` 版本校验再入库**，L015 hex 非 base64）/ `channelmixerrgb_params_blob`（v3 160B）/ `colorbalancergb_params_blob`（v5 132B）/ `nlmeans_params_blob`（16B）/ `bilateral_params_blob`（20B）/ 其余 color 组小 blob——05-02..08 各 plan 直接消费。
- **证据**：统计检验测试（`NoiseFixtureStatisticsTests` 或并入 T4）：对加噪 fixture 实测逐通道方差 vs `a·I+b`（分箱回归斜率 ≈a、截距 ≈b，容差 ±10%）、均值无偏（|Δ|<0.01）；fixture 文件数 + manifest 节。

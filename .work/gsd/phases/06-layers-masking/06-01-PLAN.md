- **action**

### T4 `LayerCompositeDriver` 退化合成 + 终端段摘出 + 跨层 ROI/dscIn 断言

- **action**
  1. `LayerCompositeDriver`（`Pipe/` 新文件）：**不改 PixelPipe**，实例化 1+N+1 个子 run——A. base 子 run（instances 剔除终端段 colorout/gamma）→ 合成输入平面 S；B. 逐层（自下而上，跳过 !enabled）：层子 run（input = 上层合成输出 C，roiHint = 合成窗口）→ 退化合成 C = C_prev·(1−op) + L·op（normal 路径，mask 缺省常量 1）；C. 终端段子 run（[colorout, gamma]，display-tail 政策原样）→ 显示平面。合成 kernel 本 plan 用最简点态 pass（blendop 全表 6-2 交付）。
  2. **跨层 ROI 一次性协商**：base 子 run forward walk 产出最终 ROI = 合成窗口 = 每层子 run entry roiHint + 终端段输入 ROI；三层 ROI 一致性 precondition 断言（照 `PixelPipe.swift:719-722` negotiated-ROI violated 模式）。
  3. **每层独立 stamp**（L021 层维度）：各层子 run stamp 自己的 `bufInROI`/`dscIn`/`iscale`；常驻断言「每层 entry dscIn == 该子 run bufInROI 首元素」；任何层借用 base dscIn 的路径一律 precondition 拒绝。
  4. 层内几何禁令（D-06-CONTEXT-5）：层链含几何槽位模块（V50Order 13/15/16/17）时 driver 拒绝执行（fatal error 语义 + 文档注释）——UI 隐藏在 6-5。
- **证据**：`LayerCompositeTests`——①恒等三元组逐字节（全 mask 直通 + normal + op=1.0 == 下层；op=0 == 下层；空链层/禁用层 == no-op）× PREVIEW/FULL 双档（L014 fence 读回）；②几何模块入层链 → 断言拒绝；③层 K 输出与「该层链单独跑 base 入口」的差异面符合预期（独立参数语义——LAYER-02 首证）。
- **防空转**：恒等断言必须逐字节（float32 位比较）非容差档；PREVIEW+FULL 两档都断言。

### T5 层缓存增量记账 + 重排存活断言

- **action** `LayerCacheTests` 扩展（记账断言，PipeCacheTests 风格）：
  1. 编辑层 K 参数 → <K 层链全 hit、K 链自 K 起 miss、>K 层**链输出全 hit**（链未变）、前缀 K..N miss（连锁失配，正确语义）、重算 = N−K 个 blend pass + K 链下游。
  2. 重排两层 → 各层链输出 key 不含顺序 → **链缓存全存活**，仅前缀失配重 blend。
  3. 可见性 toggle（isVisible=false）→ 该层跳过合成但其链输出缓存存活；enabled=false → 从处理中移除（语义区别断言）。
  4. 蒙版/blend/opacity 属性编辑 → 仅本层前缀失配（maskVersion 占位常量本 plan 下 = opacity/blend 编辑路径）。
- **证据**：每场景 hit/miss 计数精确断言（数字入测试注释 + SUMMARY）。

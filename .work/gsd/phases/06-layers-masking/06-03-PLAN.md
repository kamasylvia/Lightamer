## Tasks

### T1 stamping 原型 spike（两方案各限一天，先于一切光栅化代码）

- **action**
  1. 方案 A：render-pipeline additive blending——逐 stamp 点精灵 render pass，硬件混合累加（无原子操作）；方案 B：compute + `atomic_fetch_add`（float 需 integer 定点缩放或 compare-exchange）。
  2. 各写最小原型（单 stamp 100 次叠加目标值 1.0）：精度（累加误差 vs 理想 1.0）、吞吐（1000 stamps @ 2560 窗口）、代码复杂度三维对比。
  3. 定稿落 DECISIONS（含 hardness/density falloff 在所选方案下的实现位置）。
- **证据**：spike 报告（数字表）入 `.work/plans/06-03/` + DECISIONS 定稿。
- **防空转**：spike 判据量化（精度 <1e-5 / 帧内 stamps 吞吐 ≥ 交互预算），非「能跑」。

### T2 `GeometryPointMapper` 协议 + 五几何模块点映射 + liquify 预留

- **action**
  1. 协议：`forward(point)/inverse(point)`（全解码帧归一化坐标 ↔ 合成平面坐标）；实现 = base 链几何段**逆序复合**（几何段枚举 = V50Order 13/15/16/17 + 24.5 crop 槽位按启用实例收集）。
  2. 各模块实现：flip（仿射精确）/ crop（平移+缩放精确）/ ashift（单应逆算——04-03 H 矩阵）/ lens（径向系数逆算——04-04 系数；迭代求逆允许，精度门见断言）；**空/禁用模块恒等直通**；liquify 段预留恒等占位（6-6 接入；空 liquify 是常态路径——RESEARCH Risk 9）。
  3. 精度断言：典型参数集（crop 50% + rotate 5° + lens 默认）下 forward∘inverse roundtrip 误差 < 0.1 px（归一化坐标当量）；lens 大畸变极端档单独测（不足即触发 D-06-CONTEXT-7 降级评估——记录证据，不静默）。
- **证据**：`GeometryPointMapperTests`——roundtrip 误差表（每模块 + 复合链）+ 恒等直通 + 精度门数字。

### T3 drawn form 记录模型 + sidecar payload 冻结 + mask 缓存 key

- **action**
  1. `MaskSpec.swift`（`Layers/Masks/`）：`BrushStroke { points: [BrushPoint]，hardness/density/opacity }` / `PathForm { nodes: [corner, ctrl1, ctrl2] }` / `EllipseForm { center, radius[2], rotation, border }` / `GradientForm { anchor, rotation, compression, state: linear|sigmoidal }` / `MaskGroup { items: [(formID, op, inverted, opacity)] }`（壳——combine 语义 6-4）——字段对齐 06-RESEARCH §3.1 表（masks.h 点结构直译）。
  2. sidecar drawn payload 拼写冻结（`SidecarLayerStack.swift` optional 追加，非破坏）；maskVersionHash = `StableHash(form JSON + props)` 字段显式折叠（L013）。
  3. mask 平面缓存启用：key = (imageID, pipeType, layerID, maskVersionHash, roi)；`PipeCache` mask 档激活（6-1 占位档）。
- **证据**：round-trip 测试（drawn spec → sidecar → 解码恒等）+ 缓存 key 隔离断言（mask 变 → mask 平面 miss + 链输出 hit）。

### T4 analytic kernel 光栅化（ellipse/path/gradient）

- **action**
  1. 单通道 `r32Float` 平面；per-pixel 解析 kernel：ellipse（参数化距离 + border 羽化带 smoothstep）/ path（多边形+贝塞尔 SDF + border 内缩带）/ gradient（linear 与 sigmoidal 剖面——gradient.c:1201/:1353 公式逐式直译，解析参考 = float64 同式）。
  2. 光栅化经 `GeometryPointMapper` 逆映射（合成平面每像素 → 图像归一化坐标 → form 参数化位置）——内容锚定兑现点。
  3. 三形态 golden：解析断言（剖面上采样点逐值 vs float64 参考 <1e-6）。
- **证据**：`DrawnMaskRasterTests`——每形态 ≥3 case（含 border/feather 变体）+ compared>0。

### T5 brush stamps 光栅化（按 T1 定稿）+ eraser

- **action**
  1. stamps 光栅化：贝塞尔串插值 → 逐 stamp 径向 falloff（hardness 0/0.5/1 剖面解析断言）+ density/flow 累积语义（dt brush 行为对照）；窗口化重算天然精确（无全图 mask 缓存依赖）。
  2. eraser 语义定稿（执行期决策：负 stamp vs combine difference——落 DECISIONS）。
- **证据**：径向剖面三档 golden + 叠加累积断言（N stamps → 解析和）。

### T6 mask 腿接线 + 蒙版编辑增量语义

- **action**

## Tasks

### T1 LayersPanelView

- **action**
  1. 层列表（自下而上显示序）：每行 = 可见性眼 toggle / 名称 inline rename / 缩略 mask chip（蒙版平面低清快照——快照策略落 DECISIONS）/ opacity 滑块（D-H1）/ blend Picker（zh/en 模式名）；选中态高亮。
  2. 操作条：添加（新建调整层，默认空链 + normal + 全 mask 直通）/ 复制（新 UUID）/ 合并向下（mergeDown——6-1 数据面 + 合成语效验证）/ 删除（确认或可退——走 stackSnapshot 型 history）/ **拖拽重排（1 commit，stackSnapshot 型）**。
  3. 面板四件套全量 + `PanelWiringTests` 扩展：层操作每类恰 1 commit + 重排可退（undo 后层栈快照还原）+ opacity 拖动=1 commit + blend Picker 离散一条。
- **证据**：PanelWiring +≥6 用例名 + commit 计数精确断言。

### T2 层选中 Inspector 路由（24 既有面板零改动核验）

- **action**
  1. 选中层 → Inspector 模块面板切换为该层 chain（`IOPPanelProvider` 逐层实例化）；base 层 = 全局链现状；层内几何模块（lens/ashift/flip/clipping）**只读或隐藏**（D-06-CONTEXT-5——UI 面兑现，driver 拒绝为兜底）。
  2. 回归断言：base/层 K 面板参数互不串（编辑层 K exposure 不影响 base 实例 hash）；24 既有面板 wiring 回归全绿（零改动证明）。
- **证据**：`PanelWiringTests` 层路由组 + 全量回归绿；几何只读 UI 断言（AX 层）。

### T3 MaskToolbarView + MaskOverlayHost 绘制交互

- **action**
  1. 工具条（视口下缘浮层）：brush / eraser / gradient / ellipse / path 五工具 + 当前层蒙版绑定（选中层才可绘——无选中禁用态）。
  2. brush 参数环：size/hardness/flow/opacity + cmd-drag 调 size（C1 手势——Manual-Only 表登记）；gradient 三线交互（按下拖出 = anchor→falloff 线，两端手柄 + 旋转，linear/sigmoidal 切换）；ellipse/path 命中/手柄 = CropOverlay hit-test 模式复用。
  3. `LayerEditingState` 编辑模式状态机：蒙版绘制手势与 crop overlay 手势**互斥路由**（D-H1 归口）；笔画编辑 → maskVersion bump → 增量渲染（6-3 语义 UX 端兑现——笔画延迟 < 1 帧预算的交互目标，实测入 Manual-Only）。
- **证据**：Manual-Only 表登记行 + AX identifier 全量 + 状态机互斥单元测试（模拟双手势序列路由唯一）。

### T4 history 全粒度接线

- **action**
  1. 逐类恰 1 commit：层增删/重排/复制/mergeDown（stackSnapshot 型）/ mask 笔画（笔画结束 1 条）/ 属性（opacity/blend/可见性/rename）/ 层内参数（layerScope 型——6-1 启用位）。
  2. undo/redo 全路径回归：每类操作 undo 后层栈/参数/蒙版还原 + 渲染逐字节回到前态（抽样三类 L014 fence）。
- **证据**：`PanelWiringTests` history 组（commit 计数 + undo 还原断言）。

### T5 性能记账 + FULL 政策 benchmark（D-06-CONTEXT-8 决策点）

- **action**
  1. signpost `composite` 段记账（6-1 埋点消费）：`.work/06/perf.md` 落账——层 K 编辑增量（N−K blend pass 实测）、蒙版笔画增量、10 层全启用链稳态拖动 median（60fps 门 = `PreviewChainPerfTests` 扩展，Debug 实测数字入 perf.md）。
  2. **FULL 政策 benchmark**：fit 视图（无窗口）N 层全幅 vs 窗口化两场景实测——结论落 DECISIONS：维持「冷层不缓存」（D-06-CONTEXT-8 推荐）或回退「FULL 也缓存层输出 + 预算分档」（回退需数据支撑：实测超预算的具体数字）。
  3. `MemoryBudgetTests` 复核：100MP FULL 窗口化断言在真实大图场景复核（PERF-2 前瞻记账——正式门在 6-7 签核）。

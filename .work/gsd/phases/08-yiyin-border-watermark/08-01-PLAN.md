## Tasks

### T1 终端段尾窗扩展 + BordersModule 骨架 + 注册 + 联合布局缝

- **action**
  1. `LayerCompositeDriver` 终端段识别：`opName ∈ {colorout, gamma}` → **`iopOrder ≥ 70.0` 尾窗**（colorout..gamma 全段），段内保持 v50 排序；`tailPixelFormat` 政策回归钉（top==gamma 时 `.bgra8Unorm` 不变——borders/watermark 平面保持 float32）。
  2. `BordersModule`（76.0）骨架：Params 全参数面 = `mode: .solid(color) | .blur(amount)` / `mainImageWidthRate`（默认 90）/ `miniTopBottomMargin`（默认 0）/ `aspectRatio: (w,h)?`（nil=随主图）/ `landscapeOutput: Bool`（与 aspectRatio 互斥——yiyin actions :157-164,406 语义）/ `cornerRadius: Double?`（nil=直角）/ `shadow: Double?` / `textBottomOffset`（0.027）/ `adaptiveBackdrop: Bool`；`IOPModule` 全 conformance；`commitParams` 走 ParamsCoding + StableHash（L013）。
  3. seed enabled-neutral 恒等参数：rate=100 / margin=0 / radius=nil / shadow=nil → 画布==原图尺寸、内容逐字节不变（yiyin 语义下 bg 恰好包住主图）。
  4. 联合布局记录缝：`YiyinLayout` 接口 + 终端段子 run 组装时按段内 yiyin 实例对计算一次（空 rows 态——watermark 缺席或无行）；协议缝（driver 注入 aux vs 段内协调器查询）执行期决策入 DECISIONS。
  5. Registry 注册 borders（76.0）+ 编辑种子（identity 参数）。
- **证据**：注册唯一性断言 + seed 恒等逐字节（轨 B 中性插链 == 无实例基线）+ tail 政策回归测试 + 终端段识别扩展后**全量回归**（Phase 3-7 全模块链零增量）。

### T2 YiyinLayout float64 布局器 + yiyin node harness 布局参考

- **action**
  1. 布局器纯函数七步直译（float64）：`clacBgImgSize`（内容高驱动；主图宽/画布宽 > rate 时等比扩画布）、bg_rate 宽高比重置 + landscape 竖转横互换（init :110-131）、`calcContentHeight`（有/无文字行两态；上下边距 = max(miniTopBottomMargin, 阴影高)；textBottomOffset×bgH 文字预留）、主图居中、圆角/阴影公式（主图高×radius%/shadow%；radius 上限 50）。
  2. `Scripts/yiyin-ref-harness.mjs`：在 yiyin 正本仓跑 sharp 管线（**只读其源码/依赖，不写入 yiyin 仓**；PNG 产物写 /tmp 或 `.work/08/` 不入仓），量测 ≥8 case 的参考布局整数（横/竖/方 × aspect 重置 × landscape）。
  3. 逐值断言：Swift 镜像 vs harness 量测——整数运算精确相等 / 浮点 <1e-6；输出 `YiyinLayoutRecord`（归一化坐标，8-3 分辨率无关断言的载体）。
- **证据**：`YiyinLayoutTests` ≥8 case 逐值 + harness 量测数字入 DECISIONS/manifest + 防空转（compared > 0）。

### T3 纯色背景 + 画布合成 + 色彩换算 + ROI 扩窗

- **action**
  1. `YiyinColor`：sRGB hex → display 域（linearize + primaries 换算，ColorOutModule 同源 profile）；对 colorout 产出 profile 无感（导出腿 Phase 11 按其 profile 同式）。
  2. `YiyinKernels.metal`：画布 clear（纯色）+ 主图居中 blit 单 dispatch。
  3. ROI：`modify_roi_out` 画布扩展（dt `borders.c:429-470` basis 选择语义参考，L020 坐标系前提核对后直译）；窗口化渲染 = 视窗 ROI + 边距扩窗（liquify/retouch hint 扩窗同族）；`dscIn` 恒本 run 平面像素。
- **证据**：平场纯色取样值断言（白底中姓 + P3 display profile 下彩色背景换算值——COLOR-2 钉）+ seed 恒等逐字节 + **窗口化 FULL 画布扩展内容级断言**（扩窗后取样值位置正确，非仅尺寸记账）+ LAYER-06 层内拒绝一条。

### T4 圆角 + 投影腿

- **action**
  1. rounded-rect SDF alpha kernel（yiyin arcTo 路径语义直译；cornerRadius=nil 直角路径）。
  2. 投影平面 = SDF alpha 经 `Common/GaussianBlur`（复用，σ = 主图高×shadow%/100 的映射定标执行期决策入 DECISIONS——D-08-CONTEXT-6 同族观感定标）+ 挖空主图区 + 单次合成 dispatch 替代 yiyin mask PNG 两进程方案。
- **证据**：alpha 剖面解析断言（SDF 半径精确 / 投影带单调衰减）+ radius 上限 50 钉 + 平场门（阴影=0 时逐字节回到 T3 形态）。

### T5 模糊背景腿 + 亮度自适应蒙层

- **action**
  1. 模糊腿：输入 = borders 输入平面（主图）→ 降采样 proxy（长边 ~2048）→ `Common/GaussianBlur` → GPU 上采样；**σ = amount% × bgHeight / 100 × 0.5**（D-08-CONTEXT-6 定标式；观感 benchmark 微调允许，golden 冻结后不改式）。
  2. 亮度统计（CPU 下采样均值或 Metal reduce——执行期决策）+ yiyin 四档半透明灰罩直译（`calcAverageBrightness` RGB 均值分档 :28-46；`adaptiveBackdrop` 开关）。
  3. proxy 平面与模糊中间面折进 borders piece 辅助平面记账（D-C1 `tileWorkingSetBytesPerPixel` 先例）。
- **证据**：模糊 DC 增益=1 平场门 + 蒙层四档阈值表驱动断言（亮度边界值）+ proxy 尺寸记账断言 + 内容哈希寻址（主图不变跨参数不失效——缓存语义测试）。

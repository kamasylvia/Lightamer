### KD-1 ModelAssetCatalog：五档位常量 + Digests 分层锁定

```swift
// LightamerCore/Sources/AI/ModelAssetCatalog.swift
public enum ModelDistributionTier: Sendable { case bundled, gitHubRelease }

public struct ModelAssetManifest: Sendable, Equatable {
    public let profileID: String          // "chinese-clip-vitb16-int8" 等稳定键
    public let modelID: String            // HF repo id（OFA-Sys/chinese-clip-vit-base-patch16）
    public let revision: String           // HF revision pin（下载 URL 与 digests 双锁）
    public let embeddingDim: Int?         // CLIP 族 512/768；增强族 nil
    public let inputSize: Int             // CLIP 256；超分 tile 形状族基准（见 M2-10-06 KD-1）
    public let textLanguages: [String]    // ["zh","en"] / ["en"] / ["multilingual"]
    public let licenseName: String        // "Apache-2.0" / "BSD-3-Clause" / "MIT"
    public let tier: ModelDistributionTier
    public let releaseTag: String?        // "ai-models-v1"（版本锁死；bundled = nil）
    public let assetFileName: String      // Release 资产名（如 jina-clip-v2-int8.mlpackage.zip）
    public let hfFallback: (repo: String, file: String)  // HF/hf-mirror 兜底（revision 同 pin）
}
```

- **五档位初值**（RESEARCH §6 体积表为准，executor 核对 HF 卡片后落笔）：
  `chinese-clip-vitb16-int8`（bundled, 512d, 256², zh+en 文本塔许可 Apache-2.0）/
  `realesr-general-x4v3-fp16`（bundled, 增强）/
  `jina-clip-v2-int8`（release, 768d Matryoshka——本 plan 只存取整档，截维归 02）/
  `real-esrgan-x4plus-fp16`（release, 增强）/ `drunet-color-fp16`（release, 增强）。
- **Digests 分层（KD 必答——「内置编译期常量」对尚未转换档位的落法）**：
  `ModelAssetDigests.generated.swift` = 每档位 `digest: DigestEntry?`
  （`sha256Hex: String` + `byteCount: Int` + `generatedAt`），由
  `Scripts/ai-models/*.py` 在转换/下载产物上计算后重写该文件（GENERATED 头注，
  入仓提交——几十行文本非模型字节）。**`digest == nil` 的档位 = `store.download`
  typed 拒绝（`.digestUnpublished`）**——Release 资产实际上架是 phase 后维护者动作，
  下载器在 digest 缺席时必须 fail-closed（Alcedo 断链的直接反面）。bundled 两档
  在 T2 转换完成后 digest 必须非 nil（AC 钉）。
- **SHA-256 计算纪律**：一切 digest 由脚本对**最终分发字节**（.mlpackage 压缩包）
  计算；Swift 侧校验用 `CryptoKit.SHA256` 流式（大档内存友好，834MB 不可整载）。

### KD-2 转换脚本契约（Scripts/ai-models/）

- **CLIP 腿（convert_chinese_clip.py）**：HF 权重（revision pin）→ 官方 ONNX 导出
  语义（text seq len 固定 **52**、image 输入固定 **256×256**——**静态形状**，flexible
  shapes 伤 ANE 兼容 #1764）→ `coremltools.convert`（mlprogram，compute_precision
  FLOAT16）→ int8 权重量化（激活保 fp16；int8 激活需 A17 Pro/M4+ 不采用）→
  **L2-normalize 收进图**（文本塔与图塔输出端各一）→ `.mlpackage`。产出：
  `chinese-clip-vitb16-{img,txt}.mlpackage` + `vocab.txt`（tokenizer 词表，随包）+
  重写 digests。
- **增强腿（convert_real_esrgan.py）**：`.pth` 权重（BSD-3/MIT 实核 RESEARCH §1.6）
  → torch forward 图 → CoreML；`--format mlprogram|neuralnetwork` 双格式开关；
  spike 跑 `x4plus` 双格式 A/B（#2545：mlprogram 形态实测慢于 neuralnetwork），
  **择优格式写入 SPIKE.md 并作为该档位打包格式**（digest 对应实测胜者）。
  general-x4v3/DRUNet 用胜者格式各出一档（fp16，无 int8——超分保 fp16 保真）。
- **uv 纪律**：脚本头部声明依赖（torch/coremltools/onnx/transformers），一律
  `uv run --with ... python Scripts/ai-models/...`；产物缓存目录 =
  `~/Library/Caches/LightamerModels/`（Lumen `cache_folder` 同型三目录分工），
  最终内置资产拷入 `App/Resources/AIModels/`（`build_default_bundle.sh` 串全链）。
- **spike 附带实测（写入 SPIKE.md，M2-10-02/05/06 的输入）**：①ViT-B/16 int8
  ANE/CPU 单次前向延迟（text 52 tok + image 256²）各 20 次取中位；②两格式
  Real-ESRGAN 单 tile 延迟对比；③嵌入质量抽查——3 对中文/英文查询 × 3 图的
  相对序 sanity（人读判断，非阈值断言）。
- **网络/依赖阻塞逃生口（资源门教训）**：HF 不可达 / torch 拉取失败 → 按 E3 申报
  （记录于 SUMMARY 阻塞节），skip-gated 测试保持 skip，**禁止**伪造 digest 或用
  placeholder 字节凑 AC（E1 红线）。转换成功前 bundled 档 digest 允许 nil（T4 收口
  若仍阻塞，AC #4 按 E3 挂账处置）。

### KD-3 ModelAssetStore：resolve/download/verify/activate（actor）

```swift
public enum ModelAssetStatus: Sendable, Equatable {
    case bundled                                   // 随 app 包在（App/Resources/AIModels）
    case installed                                 // App Support 安装目录在且校验通过
    case notInstalled                              // 可下载（digest 已发布）
    case digestUnpublished                         // Release 档 digest 未出（fail-closed）
    case downloading(Double)                       // 0…1
    case corrupt                                   // 安装目录 hash 不符（下次 activate 自愈重下）
}
public actor ModelAssetStore {
    public func status(for profileID: String) async -> ModelAssetStatus
    public func modelURL(for profileID: String) async -> URL?   // bundled > installed
    public func download(_ profileID: String) async throws      // 主源→兜底→校验→晋升
    public func remove(_ profileID: String) async throws
}
```

- **下载目录** = `~/Library/Application Support/Lightamer/models/<profile_id>/`
  （ModelLocator 注入根路径——测试指向临时目录，Core 级可单测）；下载写
  `<profile_id>.tmp/<file>`，SHA-256 校验通过后**同目录 rename 晋升**（L009：
  禁 /tmp 跨卷 rename；半成品/校验失败 = 整 tmp 目录删除 + typed error）。
- **主源 URL** = `https://github.com/kamasylvia/Lightamer/releases/download/<releaseTag>/<assetFileName>`
  （catalog `releaseTag` 版本锁死）；**兜底** = `https://hf-mirror.com/<repo>/resolve/<revision>/<file>`
  再 `https://huggingface.co/...`（顺序：Release → hf-mirror → HF，国内直连友好序）。
  URLProtocol mock 测试逐源断言次序（首源 404 → 兜底接管）。
- **进度** = 每 64KB 块回调节（consumer 把 fraction 映射 BackgroundTaskSnapshot——
  M2-10-03 registry 消费，本 plan 不接 UI）；**取消** = Task cancellation 检查点
  贯穿（下载中途取消 = 删 tmp，无残留）。
- **bundled 优先**：`modelURL` 先查 `Bundle` folder reference 子目录
  （KD-4），命中即返（零下载零安装）；Release 档 bundled 恒缺席 → 走安装目录。

## 关键设计决策（planner 裁决，执行中不重开）

### KD-1 TileInference：分块纯面 + 固定形状 LRU

- **切分**：输入长边按目标 tile 形状族 `{256, 512}`（×scale 输出）网格切——
  **不补边**（Lumen 实测：输入不补边结果一致；余数 tile = 缩到族内最近固定形状
  ——LRU 缓存形状数受控）；**重叠 = 16px**（输入侧）线性 ramp 混合（权重和恒 1
  ——测试锚）。
- **LRU（ShapedSessions 同型）**：per 模型保 4 种已编译形状（worker 侧 open 缓存
  按 (profile, units, shape) 键——M2-10-05 会话缓存语义扩展 `shape` 维，帧协议
  `tile:{h,w}` 字段承载）。
- **进度比例**：`15 + 78 * done/total` 分块回调（Lumen :121 同型——解码 15%、
  分块 78%、保存 7% 三段），单调不减断言。
- **尺寸校验**：4 亿像素上限（Lumen `large_image.validate_size` 同型——100MP ×4
  = 4 亿贴线，typed 拒绝 + 文案）。

### KD-2 EnhanceEngine + worker 通道

- **编排**：读全尺寸原片渲染（编辑态 = 当前 history 渲染管线输出 float32 RGBA
  ——PipeCoordinator 渲染面消费；库态直开 = 原始解码）→ 尺寸校验 → 分块 →
  worker `run`（`inPath`/`outPath`/`tile`——**16-bit TIFF 中间帧**，大图路径
  通道零 IPC 拷贝）→ 收集 tile → blend → 输出缓冲。
- **取消检查点贯穿**：每 tile 前查 cancel；取消 = 半成品 tmp 删除 + 对话框
  close-after（busy 中关闭 = 设 cancel + 等当前 tile 结束后关——不硬杀）。
- **内存纪律**：全帧缓存先释放再分配 4× 放大内存（Lumen :103-104 注释语义——
  执行序 pin：输入渲染释放后再起 tile 循环）。

### KD-3 副本落盘：16-bit 保真容器规则 + EXIF 继承

- **容器规则（KD——「16-bit 随原格式」的落法，晨审可翻）**：
  - 原片 16-bit TIFF/PNG → **同格式**（16-bit 保真）。
  - 原片 RAW / 8-bit JPEG/WebP/HEIF → **TIFF 16-bit**（8-bit 容器回写 = 增强结果
    位深损失，违背「16-bit」目标；RAW 容器不可写是硬约束）。
  - DECISIONS 签注：JPEG 原片出 `.tif` 是本规则的**有意偏离**（M2AI-09「随原格式」
    字面收窄为「能无损承载 16-bit 的同格式，否则 TIFF 16」）。
- **reserve_copy**：目标目录 = 项目 `Media/`；`{stem}-增强-N`/`{stem}-去杂色-N`
  N 递增 1..9999，`O_CREAT|O_EXCL` 原子占位（Lumen :17-28 同型； Foundation
  `Data.write(options: .atomic)` 不具 O_EXCL——用 `open(2)` + FileHandle 或
  mkdir 竞争探测，执行时以 POSIX open 实现为准，测试钉并发占位唯一性）。
- **EXIF 继承**：`CGImageSourceCopyPropertiesAtIndex` → 输出 destination merge
  （exif/tiff/iptc 字典继承；**orientation 烘焙进像素后置 1**——渲染输出已是
  方向校正后像素）；GPS 跟随原片保留（个人工具语义，DECISIONS 签注）。
- **provenance 写入**：副本 `.lra` mint 时 `aiProvenance` 单次写入
  （operation: "upscale"|"denoise" / scale: 4 / amount: 降噪强度 / source_file:
  原文件名 / source_image_id: 原图 UUID string / backend: "coreml-worker"）。

### KD-4 导入链孪生（ImportService.importFile）

- **落相册**：`albumID` 非 nil → `LibraryStore.addImage`（可选 checkbox 默认开）。

## 风险与边界

- **100MP ×4 内存峰值**（4 亿像素 fp32 RGBA ≈ 6.4GB 输出缓冲）：超 8G MEMFAIL
  线的风险真实——缓解 = 输出按 tile 顺序直写 16-bit TIFF（流水线化，不整帧

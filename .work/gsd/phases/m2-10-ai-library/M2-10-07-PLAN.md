## 关键设计决策（planner 裁决，执行中不重开）

### KD-1 LCR 页（SettingsLCR）

- **档位列表**：五档位（M2-10-01 Catalog）逐行 = profile 名/维/许可/体积/distribution
  徽标（内置/下载）/状态（ModelAssetStatus 五态直映）；Release 档 digest 未发布
  = 「待发布」禁点（fail-closed 的 UI 面——M2-10-01 DECISIONS 语义）。
- **动作**：下载/移除（release 档）；**换激活**（CLIP 族档）= 确认对话框（「将
  重新计算全库语义索引」）→ registry `.recomputeAll(newModelKey:)` 入队（进度走
  BackgroundTask 栏——不入页内，页内只显「重算中」态）；**兼容性记录重置** =
  确认后 `CompatRecord.resetAll()`（05 面）；数据政策脚注 = 「所有语义索引与
  增强处理均在本地设备完成，不上传任何图像」。
- **纯逻辑沉 `LCRSettingsModel`**（M2-3 `LibraryInspectorModel` 同款：入参注入，
  视图零业务）；诊断探针 = worker ping + bundled 资产在场性（「AI 就绪」状态行
  ——workerUnavailable 的用户可见面）。

### KD-2 ACA 页（SettingsACA）+ LibraryConnectionStore

- **连接配置持久化拆分（安全形状）**：`LibraryConnectionStore` = UserDefaults 存
  `AIConnectionConfig`（protocol/baseURL/model/严格度/语言——**key 本体永不入
  defaults**）+ Keychain 存 key（M2-10-04 `AICredentialStore`，account 固定
  单连接键）——读写删三面 + 「连接测试」按钮（发一条最小 ping 请求，成功/失败
  行内呈现）。
- **准入前置**：baseURL 变更即过 `AIEndpointPolicy`——拒绝 = 行内红字 typed 文案
  （禁到请求时才失败）；key 缺席 = ACA 页「未配置」横幅 + 评片/描述命令呈现
  引导（点 = 打开 ACA 页）。
- **严格度/输出语言**：1-5 滑杆（rubric 语义 tooltip 摘要）+ 语言 picker（中文/
  English/跟随系统）——`AIRatingService.rubric` 消费面直通。

  修订不匹配 = LabelEngine typed 拒绝（`.prototypeRevisionMismatch`）。

  用户可查可审计（D-2「出厂常量落 label_query 表可查」字面）。

### KD-2 LabelEngine：余弦分类纯函数（Core）

```swift
public struct LabelScore: Sendable, Equatable {
    public let label: String; public let score: Float
    public let secondLabel: String?; public let secondScore: Float?
    public let margin: Float?; public let confident: Bool
}
public enum LabelEngine {
    // imageEmbedding（已归一）× prototypes（已归一）→ 全标签 score → 排序 →
    // top1 为主行；margin = top1 - top2；confident = margin ≥ threshold
    public static func classify(image: [Float], prototypes: [LabelPrototype],
                                threshold: Float = 0.05) -> [LabelScore]  // 有序全表
}
```

- **threshold = 0.05**（planner 初值；余弦 margin 经验量级——512 维 CLIP 空间
  相邻概念 margin 典型 0.02-0.15；常量单点可调，DECISIONS 签注 + 走查观察项）。
- **入库裁度**：`image_label` 行 = top 8（`top_scores` JSON 同源同 8 条）——
  全 160 标签入库 = 行膨胀无消费价值；主行判定 = 排序首位自然承载
  （PK(image_id,model_key,label) 下 top 8 即全部行，`replaceLabels` reconcile）。
- **手算锚测试**：3 维玩具向量组（同向=1/正交=0/反向=-1）+ margin/confident
  边界（恰等 threshold 双侧）逐位断言。

### KD-3 AIAnalysisRegistry：三任务型 + AI leg 消费

```swift
// App——@MainActor @Observable final class AIAnalysisRegistry
enum AIAnalysisKind: Sendable { case embedding(imageIDs: [Int64])
                               case labeling(imageIDs: [Int64])
                               case recomputeAll(newModelKey: String) }
```

- **执行序**：任务入 `registry.tasks`（BackgroundTaskRegistry 既有聚合面消费——
  栏/对话框零新增）→ 串行 `Task(priority: .utility)` 逐型执行：
  - `embedding`：逐 imageID → 256² 预缩图（ImageIO 解码 + Lanczos 缩——SessionThumbnailProvider
    档 A 重采样参照，**独立缓冲不混缩略图缓存**）→ engine.embedImage → upsert。
    进度 = i/total fraction。
  - `labeling`：前置 = 该集 embedding 已在（缺者先补一段嵌入子任务——OQ-6-A
    「嵌入完成后就地打标」语义）；engine.queryImage 原型分类 → replaceLabels。
  - `recomputeAll`：翻 `semantic_model.active`（单事务）→ 全库逐张嵌入（新
    model_key 并存写入——OQ-9-A「旧维行保留」）→ 完成后旧行**保留**（回切 =
    翻 active，无需重算）。
- **取消**：registry 级 cancel(id) + 全库重算的批量取消检查点贯穿（每张粒度）；
  取消 = 已完成行保留（增量语义，重跑幂等 reconcile）。
- **优先级语义（M2AI-07「分析期间可继续工作」）**：utility QoS + 每张之间
  `await Task.yield()`；**禁**主线程解码（ImageIO 解码在 background task 内）。
- **导入接线（LibraryProjectController.runImport 成功尾，最小半径）**：
  `await registry.enqueue(.embedding(imageIDs: 新行 ids))`（自动腿，无询问）；
  弹询腿 = `LabelingPromptController`——`labelingMode`：
  - `.ask`（默认）→ 导入完成 sheet 弹询（「用 AI 分析图片内容？」— 是/否 +
    Remember my choice checkbox）；「是」→ 追加 `.labeling` 入队。
  - `.always` → 跳问直接入队；`.never` → 不入队不弹。
  - remember 写回 = 键族 `library.ai.labelingMode`（LibraryPreferences 扩展，
    ImportDefaults 同款：常量键 + 注入 suite + reset）。

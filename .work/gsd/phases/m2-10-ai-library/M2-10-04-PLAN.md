## 关键设计决策（planner 裁决，执行中不重开）

### KD-1 凭据与 URL 准入（Core 纯面）

- `AICredentialStore`（struct + 静态方法或 actor——Keychain API 同步，包一层
  actor 隔离调用侧）：`save(key:for:)` / `read(_:)->Data`（**读出副本由调用方
  zeroize**——store 返回后即忘，句柄内不留拷贝）/ `delete(_:)`；service =
  `com.kamasylvia.lightamer`，account = 连接配置键（`rating-provider` 单连接——
  OQ-7-A 单配置，无多 profile 键爆炸）。
- **zeroize 面**：请求组装末尾 `keyBytes.resetBytes()`（测试钉：发送后缓冲全零
  ——E4 断言到字节）；日志/错误消息**永不**含 key（golden 断言错误文案无 key
  子串）。
- `AIEndpointPolicy.authorize(_ url: URL) -> Result<Void, PolicyError>`：
  scheme `https` → 放行；scheme `http` 且 host ∈ {`localhost`, `127.0.0.1`, `::1`}
  → 放行（dev 例外**无开关**——D-5 两选项中取「输入即放行」，避免暗开关）；
  其余 → `.insecureEndpoint` typed 拒绝。**存 key 前与发请求前双检**（配置面与
  传输面两道门）。

### KD-2 AIProviderClient：双协议 Codable（D-9）

```swift
public enum AIProviderProtocol: String, Sendable { case openAIChatCompletions, anthropicMessages }
public struct AIConnectionConfig: Sendable, Equatable {
    public let `protocol`: AIProviderProtocol
    public let baseURL: URL            // 已过 policy 准入
    public let model: String
    public var timeout: TimeInterval = 120
}
public struct AICompletionResult: Sendable, Equatable {
    public let text: String            // 首选 text content 拼接（双协议归一）
    public let finishReason: String?
}
```

- **请求体**：openAI = `{model, messages:[{role,content}], temperature, ...}`；
  anthropic = `{model, max_tokens, messages:[...], system?}`（rubric 进 system）。
  **响应解码**：openAI = `choices[0].message.content`；anthropic =
  `content[]` 中 `type=="text"` 拼接；错误体（`error.message` 双形）→ typed
  `.providerError(status, message)`。
- **transport 注入**：`URLSession` 协议缝（`AISession` protocol → URLSession
  conformer + URLProtocol mock conformer）——测试零网络；取消/超时走原生
  （URLSessionTask.cancel 语义直通）。
- **鲁棒解析**：模型输出常裹 ```json 围栏——`AIJSON.extract(_:)` 剥围栏 + 取
  首个平衡 JSON 对象（纯函数，golden 测试钉 4 形：裸 JSON/围栏/前后杂文/双对象
  取首）。
- **无重试自动机**（D-9 字面「重试走原生」= URLSession 超时重试面，不做指数
  backoff 层）——单次请求语义；429/5xx 直接 typed 上抛（registry/控制器呈现，
  用户手动重跑）。DECISIONS 签注此收窄。

### KD-3 评片流（AIRatingService + AIRatingController）

- **rubric 组装**：`rubricText(strictness:language:)`——严格度 1-5 各一段中文/
  英文 rubric 模板（1 = 宽松「仅明显废片」…5 = 严苛「展出标准」）；输出语言 =
  rubric 明示「用 {语言} 输出理由」。**prompt_profile_id = StableHash.fnv1a64
  (rubricText + "|" + protocol + "|" + model) 的 decimal String**（rubric 或模型
  变更 → 新 id，旧行可检可选择性重跑——D-5 护栏字面）。
- **响应契约**：要求模型回 `{"rating": 1..5, "reasons": ["…"]}`；`rating` 缺席
  或越界 → clamp 面分两支：**模型明示拒评**（reasons 非空 + rating 缺/0）→
  rating 0 哨兵行（星级列 0、reasons 必非空——有效判据同 Alcedo `ai_rating.cpp:
  11-19`）；**数值越界**（如 7）→ clamp 到 [1,5]。
- **写入序**：ai_rating append（哨兵与实星同表）→ 实星走 `images.rating` **确认
  门**：单图对话框（星级+理由+「应用」+「不再询问」checkbox）/批量预览表
  （逐行勾选或「全应用」）；「不再询问」= `library.ai.ratingConfirm` bool 偏好
  （默认 false = 恒确认）。**rating undo 无基建**（rating 不在编辑历史内——
  OQ-11-A 理由），确认门是唯一防护，测试钉「不确认不落 images.rating」。

### KD-4 描述流 + fulltext tab

- **响应契约**：`{"caption": "...", "tags": ["…"], "scene": "...", "confidence": 0..1}`

  `ai_understanding` 过滤 `active=1`（同图多行取活跃行集）** → image_id 集 →
  与 CLIP tab 同型 plan 写入（`FulltextSearchFilter.plan`）；空命中诚实空态；
  触发器同步已由 02 schema 落（KD-2 02——本 plan 只消费 + 回归断言）。

### KD-3 WordPieceTokenizer：BERT 全管线 + golden fixture

- **管线**：BasicTokenizer（空白归一 + 中文按字切（CJK 码位段）+ 标点剥离 + 小写

  用 python transformers BertTokenizer 对固定 12 句（中/英/混合/数字/长词/超长
  截断边界）产 `Tests/Fixtures/tokenizer_golden.json`（入仓，≤10KB）；Swift 断言

### KD-4 EmbeddingScanner：vDSP 纯函数 + p95 预算

```swift
public struct EmbeddingScanRow: Sendable { public let imageID: Int64; public let fp16: Data }
public enum EmbeddingScanner {
    // rows × query(dim) → top-N [(imageID, score)]（score = 余弦=点积，双双已归一）
    public static func topK(rows: [EmbeddingScanRow], dim: Int,
                            query: [Float], k: Int) -> [(id: Int64, score: Float)]
}
```

- **实现序**：`vDSP_vconvert` fp16→fp32（复用一块 dim 长度缓冲）→ `vDSP_dotv`
  （query 归一化在引擎侧做一次）→ 分数入 `k` 长度小顶堆（partial sort——10 万
  全排 ~10ms 可接受但堆更省）；零除法（双双预归一）。
- **正确性锚**：手算 4×3 维向量组（含正交/同向/反向）点积期望值逐位断言；
  fp16 往返误差带 |Δ| ≤ 1e-3（fp16 表示误差上界内）。
- **性能预算（AC 钉）**：20 万行 × 512 维合成数据 `measure` 断言 p95 ≤ 50ms
  （D-1 后手触发线——测试即触发线哨兵，超线 = fail 强制触发后手讨论）；
  1 万/10 万两档跑进 perf.md（`measure` 读数誊录，非硬断言——基线记录用）。
- **测试宿主波动防护**：预算断言用 3 次取中位（CI 环境慢机不误报；E3 记录波动）。

### KD-5 SemanticEngine + AIInferencing 协议缝（worker 预埋）

```swift
// Core——推理能力缝（02 先落 InProcess 实现；05 加 worker 实现，装配单点切换）
public protocol AIInferencing: Sendable {
    func embedText(_ profileID: String, tokens: [Int64], mask: [Int64]) async throws -> [Float]
    func embedImage(_ profileID: String, jpeg256: Data) async throws -> [Float]
}
// Core——InProcessMLModelRunner：MLModel 直接加载（bundled 资产路径注入），可单测
```

- **查询链**：text → tokenize（52）→ `embedText` → `topK` → `[SemanticSearchHit]`
  （imageID/score 有序）。**激活模型缺席**（未转换/无资产）→ typed error
  `.modelUnavailable` → 搜索对话框诚实空态文案（非静默空结果——复用 M2-3 D3
  空态族语义）。
- **图像嵌入链**（供 03 导入管线消费）：256×256 JPEG 预缩图字节（**嵌入专用
  重采样，不劫持缩略图缓存**——RESEARCH 锚点表语义）→ `embedImage` → upsert。
- **协议缝理由**：M2AI-10 要求本地推理恒走 worker（05 交付）；02..03 期间用
  InProcess 过渡 = 装配点单行切换（App 层 AIInferenceService 换 conformer），
  引擎/Store 零改动（DECISIONS 签注过渡语义）。

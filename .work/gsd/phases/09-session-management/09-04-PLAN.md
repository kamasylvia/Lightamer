## 纪律（强制）

- **每任务独立提交**（Conventional Commits，只 add 相关文件）；`caffeinate -dis`；单测 `Scripts/test-direct.sh '<Class>'`（L019b）。
- **每任务边界检查 `.work/config.toml [gsd]` 开关（`auto`/`paused`）**——任务收尾 commit 后、下一任务开工前：`paused=true` 全链路停（在制品已 commit、工作区干净地停、报告断点）；`auto=false` 完成当前任务后停等用户「继续」。
- **懒渲染红线（review 检查项）**：批量 apply 段1-2 **禁止触发任何像素渲染/解码**（grep 检查项 = `SessionBatchApplier`/`BatchSidecarWriter` 零 `PixelPipe`/`RAWDecoder` 引用）；缩略图只置 `thumb_state=stale` 交 9-3 后台再生（dt「只失效不重渲」`history.c:997` 同构）。
- **真身恒 sidecar 契约（D-09-CONTEXT-4）**：段2 claim 后、段3 落盘前，一切读路径（reconcile/load/重建）以 sidecar 为真；`dirty=1` 行 `params_hash` 列标注「待生效」；崩溃恢复 = dirty 行按 sidecar 重读覆盖索引。任何「信索引参数」捷径 = FAIL。
- **PERF-07 门纪律（L009）**：10k sidecar fixture（tiny 原片占位 + 真 `.lra` JSON）建在**临时目录（SSD）**；门数字在**内置 SSD 复核一次后钉**入 perf.md；UNITEK 卷数字只记录标注卷型。段3 与缩略图再生**只计量不设门**。
- **undo 语义边界**：每目标图各得一个 commit（快照 = paste 后实例集）；跨图全局 undo 组 v1 不做——UI 文案禁暗示「一步撤销整批」；单图 ⌘Z 立即可用是断言项。
- **live 保护**：目标图正被编辑 → 批量循环跳过 + 走交互层 live paste（`_safe_history_job_on_imgid` 同款）；否则双写竞态。
- **防空转**：三式语义测试含反向断言（overwrite 后目标图实例集 == 载荷非超集；merge 后同名 (opName, multiPriority) 仅存 latest）；before/after 逐字节 + **渲染计数断言**（hold 快路径零重渲）。
- **L014 fence**：before/after 与 peek 渲染一切 GPU 读回先 drain。
- RESEARCH 未覆盖细节（写队列聚批参数/进度上报形态/载荷 Codable 拼写/blit shader 变体签名）标注**执行期决策**入 `09-04-DECISIONS.md`。

### T2 paste 三式 + live 保护 + 单图 undo（HIST-05 paste 侧）

- **action**
  1. `PasteSemantics`（Core/History/）：①**overwrite** = 目标 history 重置为「默认种子 + 载荷实例」单 commit（层栈 = 载荷层栈快照）；②**merge** = 载荷实例逐个 commit——`effectiveChain` (opName, multiPriority) latest-wins 天然处理同名覆盖（既有语义验证不新造）；③**partial** = 载荷先过勾选集再走 merge/overwrite。
  2. live 保护：目标图 == 当前编辑图 → 走 EditorState/coordinator live 路径 + 正常 commit；批量循环跳过 live 目标。
  3. 菜单三件（Copy Adjustments / Paste to Selected / Paste Partial…）+ `PastePartialDialog`（模块树勾选，IOPPanelProvider 模块清单复用；面板四件套）。
- **证据**：`PasteSemanticsTests` paste 段——三式各一 case（overwrite 后实例集 == 载荷**精确**；merge 后同名 (opName, multiPriority) 仅存 latest + 异名共存；partial 勾选子集恰落）+ live 保护断言（live 图被批量循环跳过且交互 paste 成功）+ **单图 ⌘Z 恰 1 撤销本次 paste**（commit 计数 + 还原逐字节）。

### T3 批量管线段1+段2：内存变换 + 索引单事务

### T4 段3 sidecar 批量写队列 + dirty 自愈 + 崩溃注入

- **action**
  1. `BatchSidecarWriter`（Core/Session/）：后台 actor 串行队列（机械盘并发负收益——串行钉死）；每 target = JSON encode（pretty+sortedKeys）→ 同目录 `.tmp-<uuid>` → `replaceItemAt`（`writeAtomic` 同款形态）→ 成功后索引独立小事务 `dirty=0`；有界队列 + 进度上报（UI 可见后台过程，dt progress message 同语义）；退出/切会话 → flush 余量（SessionCoordinator teardown 缝挂接）。

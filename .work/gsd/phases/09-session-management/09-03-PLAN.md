# Plan 09-03 — 浏览模式（SESS-06 + PERF-06 基线）

> 背景：会话的「脸面」plan——grid/单图/culling 三模式 + **缩略图双档管线**（吞吐的
> 关键决策）：未编辑图直读 RAW 内嵌 JPEG 预览（ImageIO，~10-50ms/张），已编辑图/stale
> 再生走真 pipe `PixelPipe.process` @ `.thumbnail` 360px（编辑后真实观感，含层栈/
> 印框——Phase 8 `terminalTailFloor` 契约随用随验）。**缩略图绝不进 PipeCache**（独立
> 磁盘缓存 + 256-512MB LRU；PipeCache 只服务当前编辑图——10k×0.35MB 洪峰会冲垮 3GB
> 预算挤掉当前编辑图平面，D-C1 语义破坏，review 检查项）。culling = 2 图并排各自
> PREVIEW 子管线（D-09-CONTEXT-6 cap 2，错峰 decode 防解码风暴）。rating overlay 只
> 布局不接数据（Phase 12）。**PERF-06 = 基线计量在本 Phase 建立**（60fps 门 Phase 15
> 清算）。GUI 验收轮 = 真会话文件夹走查。

## Tasks

### T1 collection 行模型 + ThumbnailMemoryCache LRU

- **action**
  1. `SessionBrowserModel`（App/Session/）：行模型 = 索引行投影（path/dir/filename/has_edits/orphanSidecar/thumb 状态）+ 内存缩略图引用（不持 MTLTexture）；collection 查询面 = `SessionIndexStore` 排序读取（`ORDER BY` 列在 schema；filter UI Phase 12）——10k 行内存数组零压力；多选状态（⌘/⇧ 语义数据面）。
  2. `ThumbnailMemoryCache`（Core/Session/）：path→CGImage LRU，byte 预算构造注入（默认 256-512MB 区间取值执行期决策），超预算逐出最旧；线程安全 actor。
- **证据**：`ThumbnailMemoryCacheTests`——注入小预算逐出序列精确（逐出顺序 + 驻留字节 ≤ 预算断言）；hit/miss 计数；并发访问 smoke。

### T2 磁盘缩略图缓存 ThumbnailDiskStore

- **action**
  1. `.lightamer/thumbs/<pathhash>.jpg` 读写（pathhash = relPath 稳定哈希，L013 语义——执行期定算法入 DECISIONS）；索引行 `thumb_path/thumb_params_hash/thumb_state` 绑定；删除行时清理对应 thumb 文件（9-1 removed 腿挂接）。
  2. round-trip：写→读→CGImage 逐字节等价（JPEG 有损域内 = 重新编码恒等断言或字节比对，执行期定口径）；params 变更 → `thumb_state=stale` → 再生后 `thumb_params_hash` 更新。
- **证据**：`SessionThumbnailProviderTests` 磁盘段——round-trip + stale 再生 hash 翻转 + 预算规模估算落 perf.md（360px JPEG ~30-60KB × 10k ≈ 0.5GB 上限注记）。

### T3 双档管线档 A：ImageIO 嵌入预览

- **action**
  1. `SessionThumbnailProvider`（Core/Session/，App 无关可单测）：档 A = `CGImageSourceCreateThumbnailAtIndex` 读 RAW 内嵌 JPEG 预览（`kCGImageSourceThumbnailMaxPixelSize` ≈ 720 超采样留缩放余量——执行期决策）；失败（无嵌入预览图）→ 回落档 B 渲染一次（回落记 DECISIONS，头注钉「嵌入预览缺失是相机域事实」）。
  2. 色彩域口径：嵌入预览多为 sRGB/P3 vs pipe Rec2020→display——缩略图尺寸下理论不可辨，**真样张抽检钉口径**（T7）。
- **证据**：档 A 单测——真 RAW fixture（Phase 1 既有 DSC00012.ARW 等）产非空 CGImage + 尺寸上界断言；无嵌入预览 fixture → 回落腿触发断言；吞吐记录（~10-50ms/张量级）。

### T4 双档管线档 B：PixelPipe THUMBNAIL + 后台队列

- **action**
  1. 档 B = per-image 独立 `RAWDecoder.decode` → `PixelPipe.process` @ `.thumbnail`（**绕开 coordinator 单图状态机**；层栈复合语义与 `renderCurrentChain` 等价——`LayerCompositeDriver` 同一 driver，`terminalTailFloor`/yiyin 注入契约不动，回归钉）；输出 CGImage → 磁盘缓存 + 索引行更新；**只在需要时渲染一次**（fetchThumbnail LAZY 范本：磁盘命中或已渲染即返）。
  2. 后台队列：并发 2（Neural/GPU 与编辑器竞争——Phase 7 同教训）+ 可见优先（滚动中可见 cell 插队）+ 空闲调度（批量再生让位交互——dt backthumbs crawler 对标语义）；会话切换全部任务 cancel（9-1 teardown 缝②接真）。
  3. **PipeCache 隔离断言**：双档渲染前后 `cache.totalBytes` 不变（常驻回归）。
- **证据**：`SessionThumbnailProviderTests` 档 B 段——edited fixture 渲染非空 + 与磁盘 round-trip 恒等 + stale→再生→hash 翻转；隔离断言绿；调度语义单测（可见优先插队 + cancel 全清）。

### T5 grid 视图（LazyVGrid + cell + 多选 + 菜单）

- **action**
  1. `SessionBrowserView`：LazyVGrid + cell 复用（lazy 语义）；cell 四件 = 缩略图（LRU/磁盘命中 → 占位渐显）+ edited 徽章 + 孤儿徽章 + rating 星 overlay（**布局不接数据**——Phase 12 填数，头注钉）；渐进 ingest 接线（扫描流边吐边出）。
  2. 多选（⌘/⇧ 数据面已备）+ 右键菜单 = 复制调整/粘贴/粘贴部分…/（标记项 Phase 12 占位禁用态）；双击 cell → 单图模式 + `EditorState.load` 既有链。
  3. 模式切换：ContentView 工具栏 segmented（网格|单图|对比）**整页替换**（浏览器不挤压编辑视口布局，浏览模式 Inspector 隐藏——v1 范围控制）；三态 `browser.mode.<grid|single|culling>` identifier。
- **证据**：cell 四件 identifier 全量；菜单项 zh/en catalog（L025）；渐进 ingest 时序断言（首屏 cell 早于全扫完成——9-1 流复用）；多选语义单测（⌘ 累加/⇧ 范围数据面向量）。

### T6 culling 对比视图（cap 2）+ 单图模式接线

- **action**
  1. `CullingView`：2 图并排，每格独立 PREVIEW 子管线（各自 `RAWDecoder.decode` + 减半 bucket `PreviewBucket.ladder`）——自持平面（禁进 PipeCache）；**错峰 decode + 进度占位**（防 4×→2×100MP 同时全解码 hitch）；cap 2 常量（4 图扩展位头注）。

  3. 单图模式 = 现有编辑器视口原样（无新管线）——接线验证一行。
- **证据**：`CullingPipelineTests`——两格子管线相互隔离（A 改参数不影响 B 平面逐字节）+ cap 2 拒绝第 3 图（typed 上限）+ 关闭后平面释放（内存账本归零）+ L014 fence 读回。

### T7 双档一致性 + 观感抽检钉口径

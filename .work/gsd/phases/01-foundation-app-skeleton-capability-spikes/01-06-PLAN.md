# Plan 06 — Test skeleton (LightamerTests + LightamerUITests) + module API.md contracts (D-03c) + perf baseline

## Goal

Wrap the Phase 1 vertebra in verification and document the module API contracts. Four deliverables: (1) **fill in the test stub bodies** that Plans 02-04 created (`RAWDecoderTests`, `MetalContextTests`, `IOPModuleTests`, `V50OrderTests`, `LayerSkeletonTests` + new `MetadataTests`, `AppErrorTests`, `ModuleBoundaryTests`) — testing through the `public` surface per RESEARCH Validation Architecture; (2) **`LightamerUITests`** — `AppLaunchTests` verifying the shell launches, dark mode, empty state (FOUND-01/05); (3) **three `API.md` files** (D-03c — one per module: `LightamerCore/API.md`, `LightamerIOP/API.md`, `App/Sources/Lightamer/API.md`) listing the public surface vs internal implementation as a human-readable contract index; (4) **`os.signpost` perf baseline** — record the Phase 1 baseline measurements (decode time, display time, memory, GPU time) against the D-32 hard budgets, producing `01-PERF-BASELINE.md`.

This is the Wave 2 validation wrapper around Wave 1 (Plans 01-04). It does not add new product features — it verifies the vertebra is structurally sound and documents the contracts Phase 2+ will extend.

## Tracer vertebra mapping

Wave 2 plan #2. Validates the vertebra end-to-end. After this plan: the test suite is green (framework ready, coverage not the goal per D-28), the module boundaries are documented, and the perf baseline is recorded for Phase 2 comparison.

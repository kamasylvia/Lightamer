# Plan 03-04 — shadhi + sigmoid

## Goal

两个「域内新地形」模块：IOP-TONE-04 shadhi（Phase 3 第一个需要邻域模糊的模块——域内大半径模糊首战）与 IOP-FILM-02 sigmoid（**D-T2 sigmoid 先行**：scene-referred tone mapping 的风险缓冲，为 03-06 filmicrgb 攻坚建立测试基线、面板与缓存全链路）。

**shadhi 范围决策（见 T2 checkpoint）**：gaussian 腿先进，bilateral 腿参数位保留后置——dt_bilateral 网格移植与 Phase 5 IOP-DENOISE-03 共享基建，届时一并落；golden 案例全部钉 `shadhi_algo=gaussian` 使两侧同算法可比。

**Lab 域显式（checker finding，shadhi 侧）**：shadhi 模糊底与 overlay 数学全在 **Lab 域 L 通道**（shadhi.c:356-490）——复用 03-03 T1 `LabRoundTrip`，这是本 plan 依赖 03-03 的唯一硬原因。

**sigmoid 输入语义 caveat（RESEARCH §3/§Summary#5）**：`display_white/black_target` 是输出端参数，默认值与输入域无关可直接用——这是 sigmoid 比 filmicrgb 稳的直接原因；但 CIRAW displayed-domain 输入下 middle_grey 等场景端默认值在真机 RAW 上需校准（产品语义任务，与 parity 解耦，模块头注记）。

## Must-haves

- Registry 注册：shadhi v50=50.0、sigmoid v50=45.3（V50Order 确认值）

- `Common/GaussianBlur`（separable，sigma→pass 结构）——shadhi gaussian 腿 + 后续模块复用件
- shadhi `.swift + .metal`：Lab L 域模糊底 + overlay 标量式逐式直译（`shadows_xform`/`highlights_xform`/chroma_factor，shadhi.c:399-490）；`shadhi_algo` 双值枚举保留
- sigmoid `.swift + .metal`：CPU `commit_params` 四标量推导（`paper_power=5^(−skew)`、数值差分 `film_power`、`film_fog`、`paper_exposure`；MIDDLE_GREY=0.1845）+ 双 kernel（per_channel 含负值去饱和 + hue/energy 保持；rgb_ratio 含双曲 gamut 压缩）
- sigmoid golden parity <1e-5（scene-referred 基线建立）；shadhi golden（gaussian 腿钉参）<1e-4 + ΔE<1.0（99% 分位）
- D-T2 兑现：sigmoid 先于 filmicrgb 落地，sigmoid 面板 + 缓存 + golden 链路成为 filmicrgb 的兜底与模板

# Plan 03-02 — WB + 吸管 + Inspector 面板框架（D-T4 / D-T6）

## Goal

交付 IOP-TONE-02（temperature/white balance 含吸管），同时建立 D-T6 Inspector 参数面板框架（`IOPPanelProvider` + `LightamerSlider` + D-H1 三件套接线）与 D-T4 色彩采样 plumbing（WB 吸管与后续 filmic auto 三键共用）。exposure + temperature 成为前两个真实面板——Plan 03-01 的 exposure 模块在此获得 UI 出口。

**域语义（已定，RESEARCH §1.2/§5）**：dt 的 Kelvin→增益工作在传感器域（需 per-camera XYZ_to_CAM 矩阵）；Lightamer 的 WB 是 CIRAW 后的 post-hoc 校正层——Kelvin→增益走 **Rec2020 原生换算**（SPD→XYZ→Bradford→Rec2020 白点 T，`gains = W/T`，W=D65 在 Rec2020 下 = (1,1,1)）。吸管路径与 dt 完全同构（通道比值与域无关）。

## Must-haves

- temperature 模块 `.swift + .metal` 文件对（v50 位次 3.0 保留 + 模块头注记 post-CIRAW 校正层 divergence——零表变更，RESEARCH Open#2 采纳）
- K→gains CPU 推导 + CMF/SPD 数据表（`cie_1931_std_colorimetric_observer`、`cie_daylight_components` 随 temperature.c 头部常量搬移，约 100 行）
- 吸管端到端：viewport 点击 → PREVIEW 采样（fence 后读，L014）→ N×N 面积均值 → `gains = normalize(1/picked)` 绿归一 → 单次 history commit
- `IOPPanelProvider` 协议 + `LightamerSlider`（D-H1 三件套映射）+ InspectorState 按 opName 分发 factory
- exposure + temperature 两个真实面板可拖动，60fps 预览 + drag-end 恰 1 条 HistoryItem
- golden：三通道增益直设钉参（绕开 Kelvin 域差，RESEARCH §5），parity <1e-5

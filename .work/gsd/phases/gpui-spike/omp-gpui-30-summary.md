# gpui 30-module panel — summary

**结论头**：30 个模块的面板，滚动 58.0 fps（间隔中位 16.64 / p95 18.05 ms，>33.3 ms 帧 0/67），展开 5 个填充模块后再滚 57.7 fps（16.69 / 17.55 ms，>33.3 ms 0/67）——两项都跟住 60 Hz 面板。**拖滑杆一项未测成**：合成 `leftMouseDragged` 只让应用重绘 1 个中间帧（40 步），无法计量实时帧率；同机制视口拖动对照 60.7 fps，缺口定位在滚动面板子树的拖动投递/重绘路径。

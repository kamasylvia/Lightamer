  OQ-7 降载尝试的**对照基线**（与 T3 后复测同表对账）。

### KD-3 nlmeans bounded 降载尝试（OQ-7-A，唯一改码半径）

- **杠杆点**：`PixelPipe.swift` nlmeans 预览降载判定（pipeType = PREVIEW/THUMBNAIL
  时的 K clamp + decimate + window 档位；在案 57 趟档 = K=3 + decimate=57）。
- **尝试序（一次 bounded，最多三档试）**：①K 3→2 ②decimate 57→更深（如 65/73）
  ③window 半径缩减——逐档复测 KD-2 ②数字，取**达 ≤16.6ms 的最浅档**；全不达 =
  取数字最优档**不落地**（改动 revert，数字与档位进 perf.md 挂账记录）或落地为
  V2 备选语义（DECISIONS 裁定，默认 revert——不为凑门牺牲预览观感无据）。
- **质量观察项**：任何落地档 = 预览观感 trade-off，GUI 验收轮（M2-11-05）顺带观察
  （nlmeans 拖动时预览降噪质感）；登记进 perf.md 档位表备注列。
- **回归红线**：FULL 桶与 THUMBNAIL 360 档零变化（降载只动 PREVIEW 桶判定）；
  golden/parity 套件零回归（`--bundle IOP` + IOPParity 定向轮全绿；若 parity 面涉
  PREVIEW nlmeans 需重钉 = 如实 DECISIONS 登记重钉依据，禁静默调 golden）。

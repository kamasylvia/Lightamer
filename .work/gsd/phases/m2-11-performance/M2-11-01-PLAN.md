### KD-1 test-direct.sh 解析函数抽取（可回放缝）

- `run_bundle` 内「日志解析 + 判定」段（:160-199 记账解析、verdict 判定）抽成独立
  函数 `parse_bundle_log <log> <filter>`；`run_bundle` 保留执行 + RSS 采样 +
  **BUNDLE 行组装**，判定改调 parse 函数——**生产行为逐字节等价**（重构前后对
  normal.log 输出一致，selftest 负责钉）。
  > checker 回注（2026-10-07，m4）：parse 职责面明确为——**判定逻辑全在 parse 内**
  > （executed/skipped/failed 计数、summary_fail 合并、crash/no-total-line/MEMFAIL/
  > ANE-DEGRADED 判定；MEMFAIL 依赖 log 内 `maximum resident set size` ru_maxrss
  > 解析，该解析归 parse）；**「BUNDLE 行组装」留 run_bundle 拼装**。stdout 输出面 =
  > 五字段一行：executed/skipped/failed/verdict + peak/sampling 判定对（与 BUNDLE 行
  > `N/N/N|peakRSS=…MB|sampling=…` 段同构）；stderr = ↳ 诊断行。selftest 断言随
  > 五字段面对齐（normal.log 逐字段含 peak/sampling）。
- **可 source 守卫**：脚本头部加 `LA_SELFTEST=1` 短路——设了该 env 只定义函数后
  `return 0 2>/dev/null || exit 0`（不执行 bundle 注册表之后的主体）；
  `test-direct-selftest.sh` `source Scripts/test-direct.sh` 后直接调
  `parse_bundle_log` 喂 fixture 断言。守卫必须保证：不设 env 的正常调用路径行为
  零变化（首行 `set -euo pipefail` 等语义不动）。
  > checker 回注（2026-10-07，m7）：守卫写 `return 0 2>/dev/null || exit 0` 形态——
  > 被执行（非 source）路径下 zsh top-level 裸 `return` 报错；双形态兜底两种消费
  > 方式（source / 执行自检模式）均干净退出。

### KD-2 L055 修复语义（崩溃签名 → FAIL + 总计行校验）

1. **崩溃签名扫描**：日志含 `terminated abnormally` **或**
   `Restarting after unexpected exit` → verdict=`crash`（FAIL，入 ANY_FAIL）。
2. **末条 Executed 行身份校验**：末条 `Executed N tests` 行必须挂靠
   `Test Suite 'All tests'` 段（xctest 末尾总计行形态 =
   `Test Suite 'All tests' passed/failed … Executed N tests`）；末条 Executed 行
   来自非 All tests suite（= 类 suite 截断形态，恰是 L055 假绿签名）→
   verdict=`no-total-line`（FAIL）。两检查叠加：正常轮两者皆过零误伤
   （normal.log fixture 钉）。
3. **单数兼容（#5 一行修）**：`:162` 判据 regex `Executed [0-9]+ tests` →
   `Executed [0-9]+ tests?`（`Executed 1 test` 单数形态匹配）。
   > checker 回注（2026-10-07，m1）：单数修覆盖**两处**外层同一 regex——:162
   > executed 判据与 :165 summary_fail 外层 `^Executed [0-9]+ tests`（同为复数限定，
   > 单数轮 summary_fail 恒 0；失败计数走 `' failed (` 行仍正确，无正确性洞，但
   > 「:165 已兼容零触碰」结论不成立）。内层 `with [0-9]+ failures?` 本就兼容单数，
   > 零触碰。

### KD-3 ANE 态自检注记（#1 观测件）

## 风险与边界

- **fixture 保真**：crash.log 构造若与真宿主输出形态有差（time 前缀/颜色码），以
  L055 现场 `.log` 为准尽量逐行复刻；selftest 只测 parse 函数（不测执行段），
  形态差不影响判定语义。
- **总计行校验的过滤轮兼容**：类过滤轮（`-XCTest` 单类）末条 Executed 行 = 该类
  suite 而非 All tests——校验必须以**过滤参数在场**为豁免条件（filter 非空 →
  不做 no-total-line 判定），否则过滤轮全线误伤（KD-2 实现细节，selftest 补一
  过滤轮形态负证可选项）。
- **硬化选型失败**：两案选型（序注入/轮询）都压不住复现 → 停下报 orchestrator
  （不自行加 sleep 类伪修复）；台账记选型失败事实， revert 面保持测试原语义。

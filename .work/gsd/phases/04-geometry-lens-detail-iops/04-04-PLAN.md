# Plan 04-04 — lens correction（三层：CIRAW 直通 / 手动滑块 / Lensfun XML 只读）

## Goal

交付 IOP-GEO-03，实现 04-CONTEXT **D-G1 三层策略**：

- **(a) CIRAW 内嵌直通（零代码，文档化）**：Phase 1 已实证 CIRAW 对支持的镜头自动应用 DNG OpcodeList/厂商 opcode 校正——解码数据已含内嵌校正。模块头 + 面板写明防双补；lensfun 的 `mods_done` 重检测不可用（无 C 库），以「手动层默认 off + UI 提示」替代——记录为已知取舍。
- **(b) 手动滑块（Metal warp，默认中性）**：单一融合 kernel `lens_manual_warp`——径向畸变 `rd = ru·(1 + k1·ru² + k2·ru⁴)` backward 采样、横向 CA 逐通道半径缩放（R `r·(1+tcaR)`、B `r·(1+tcaB)`、G 原位——lensfun TCA linear 语义）、渐晕 `I' = I·(1 + k1r² + k2r⁴ + k3r⁶)` **乘在采样之前**（dt `lens.cc:1194-1206` 顺序一致）。k 全 0 → 恒等（ROI/缓存零扰动）。
- **(c) Lensfun XML 只读（本 plan 后半）**：Foundation `XMLParser` 解析（本机实测 55 xml 共 **4.2MB**，schema 平坦两层全属性驱动）；EXIF maker/model/lens 匹配 → 焦距选择 + vignette 三维插值 → 参数归一到 (b) 的内部模型，喂**同一个** kernel（D-G1 字面要求）。不链 C++（依赖红线永不），数据文件不入 git。

槽位 13.0（V50Order 现表已有，dt 注释 cacorrectrgb 13.5 在 lens 后防 lensfun 重引入 CA——(b) 层同位置受益）。

## Must-haves

- `LensParams`：distortionK1/K2、tcaR/tcaB、vignetteK1/K2/K3（默认全 0 = 中性恒等）+ 数据来源标记（manual/lensfun/off）
- `lens_manual_warp` 融合 kernel：畸变 + CA + vignette 一 pass；顺序 = 先 vignette 乘后查样（lens.cc 语义）
- ROI：k 全 0 → modifyROIOut/In 恒等；非零 → forward 边框点 AABB + 边距（`lens.cc:1697-1790` 逆变换模式）
- `LensfunDB`：XMLParser 逐文件惰性加载 → `[LensEntry]`；模型覆盖 distortion（poly3/ptlens/poly5）、tca（poly3/linear）、vignetting（pa 三维网格）
- 匹配：归一化（lowercase/去品牌前缀/去 "f/" 焦距段）→ 等值/包含 + cropfactor 近似校验；**miss 率在测试里落账**
- vignette 三维插值：focal/aperture/distance 各维线性 + 端点 clamp（~50 行，语义对照 lensfun C `lfModifier`——实现期读 GitHub 源定稿）
- 归一化半径约定（半宽 vs 半对角）**与 Lensfun 对齐**——实现期对照 `modifier.elaborate` 钉死（research 标 Med，checkpoint 承载）
- 数据分发（research Open Q4）：**首跑下载整库 4.2MB 落 Application Support + 设置可指路径 + 网络失败/miss 降级手动层**（推荐，checkpoint 确认）
- golden：合成 float64 径向 warp + vignette 公式参考（L017 路线①——warp 空间变化算子）；uniform 探针（k=0 恒等、vignette 平场衰减公式点检）；XML 解析 golden（固定子集钉参数）

## Tasks

### T1 GUI-1 判别探针（只诊断不修复，独立提交）

DEBUG 构建加临时探针（`#if DEBUG`，修完 T5 删除或转常驻诊断日志）：
1. `PipeCoordinator` 渲染完成后 log `displayTexture.pixelFormat` + 中心/四角各 1 像素值
   （`MTLTexture.getBytes` 单像素读回，L014 fence 纪律）。
2. 若 pixelFormat == .bgra8Unorm：读回值应为 sRGB 编码域（正常曝光照片亮部 ≥128）；
   若为 float32：确认走了 fallback 路径 → 定位「gamma tail 未达 displayTexture」的原因
   （texture 选择错？gamma 实例 disabled？尾平面 format 分支错？）。
3. 同时 log RAWDecoder 输出 ciImage 的 extent 与（经 CI leg convertTexture 后）首平面
   中心像素值，判定 CIRAW 输出域（scene-linear vs display-referred）与管线假设是否一致：
   对照测试侧 `decodeFixtureEXR`（float EXR 直读）与 app 侧 CIRAW 解码的域差异。
4. 探针跑 DSC00012.ARW，产出判别结论 → 写入 `04-06-DECISIONS.md`（D-GUI-1：根因 +
   证据 + 修复方向）。**预期候选**（按可能性）：a) displayTexture 选到中间平面而非
   gamma 尾平面；b) 实机链 gamma/colorout 实例未启用或被 displayProfile 折叠改参；
   c) CI leg 输出域/预乘错导致管线输入域错。

### T2 GUI-1 修复

- 按 T1 证据修复。修复面预期在 App/State 层（texture 选择/链启用/CI 域），Core 管线
  **不应**需要改（轨 B 单测已证管线输出正确）——若诊断指向 Core，先在 DECISIONS 里
  论证再动手。
- 单测回归：全套绿。若修复涉及可单测的纯逻辑（如域转换），补单测。

### T3 GUI-2 + GUI-3 修复（同根：显示 blit 几何）

- 现状：大三角形 + UV 计算）斜边越界区可见（白色对角线）+ 绘制平面超出 aspect-fit
  矩形（800×1120 vs 3:2 fit 800×533）。
- 重写显示几何：**顶点矩形 draw（4 顶点 triangle strip，顶点即 fit 矩形）** 替代大
  三角形 + UV clamp——letterbox 由 renderPass clearColor 承担，绘制约束在 fit 矩形内，
  越界伪影结构性消失。`aspectFitUniforms` 的 fit 数学（ViewportFit 同源公式）只算
  顶点位置，UV 恒 [0,1]×[0,1] 全纹理。
- 注意 EDR/色彩空间不回退：displayReady passthrough 语义、layer colorspace 附加
  （D-COL2）保持原样。
- 单测：如 fit 数学有可提取纯函数，补 `ViewportFitTests` 对应用例。

### T4 GUI-4 布局占比（红线落地）

- 现状：990pt 窗口三列近似均分，Inspector 与视口等宽。
- 目标（AGENTS.md「GUI 布局红线」）：编辑视口 = 视觉主体。具体：
  - 会话侧栏：默认折叠（或空态收成窄 icon 列 ≤48pt），展开 ≤220pt。
  - Inspector：默认宽 ≤300pt（建议 260-280pt），可折叠。
  - 视口：吃满剩余空间；990pt 窗口下视口宽 ≥ 窗口 50%。
- min/max 约束落在列定义处；空态文案不撑宽。

### T5 GUI 复验闭环 + 探针清理 + 签收

1. 删 T1 临时探针（或转 `#if DEBUG` 常驻诊断，DECISIONS 记录选择）。
2. 按 PLAYBOOK §2 全流程复验 DSC00012.ARW（观察层量化）：
   - GUI-1：视口 ≥128 亮度像素占比显著上升（灯笼区出现饱和红像素 >100 px）；
     全图 <16 占比降至 letterbox 合理值。
   - GUI-2：视口内无白色对角线（越界区 = 纯 letterbox 色）。
   - GUI-3：图像绘制边界 == fit 矩形（量化：图像内容外包络 ≈ 网格外包络）。
   - GUI-4：990pt 窗口实测三列宽 + 视口占比 ≥50%。
   - 截图证据存 `.work/gui-acceptance/2026-09-2*-fix-*.png`，FINDINGS.md 逐项闭环。
3. 全套单测最终绿；UPDATE FINDINGS/LESSONS（新增教训：显示腿无单测覆盖 → GUI 验收

## 现在的起点（塔台看的，每一条你自己核）

- 引擎只在草稿会话上编辑过照片：照片放内存，每张一个历史栈，第一步的标签是历史模型里定的 `import`。**真实会话里现在没有照片**（导入是 B15），编辑命令在上面跑只会得到「没有这张照片」。
- 引擎的「出错后状态不变」是这样做的：每次 `execute` 之前把整个状态克隆一份，出错了恢复。草稿会话里没问题；真实会话里一张照片改一步也要克隆所有照片的栈，而且库那一半它管不到。要换成上面 T5 的三步。
- 前一半把第 0 步的标签写成了 `seed`，那是照塔台任务书的字面做的，塔台的任务书写错了（`seed` 只出现在引擎一个测试辅助函数里）。**塔台的裁定：库跟历史模型走，用 `import`。**
- 历史模型只能用一份初始设置建栈，再一步一步提交；没有「从存好的步重建一个栈」的办法。
- 前一半查到：历史模型读设置时，一个按顺序排的 JSON 数组也会被读成合法的设置（`[1, 2]` 读成格式版本 1、处理版本 2）。这一波不修它，你知道就行。

## 要做的

**1. 历史模型补三个小接口。** 只许往里加，不许改已有的东西；已有的测试一个都不许改，全部照旧通过；设置序列化出来的字节一个都不许变。

- 把第 0 步标签那个常量公开出来（现在是私有的），让库里和引擎用同一个出处。
- 从存好的步重建一个栈：给它每一步的标签和设置，再加游标在哪。游标越界是错误。重建出来的栈和一步步提交出来的完全一样（步数上限的规矩照旧）。
- 「把别的照片上的调整合并进来」的纯函数：给它目标照片当前的设置、来源设置，再给一个选择（要哪些模块，或者要哪些模块的哪些参数）。按选择合并：选中的模块实例在目标里替换或新增，没选中的一个都不动；目标的处理版本号不变。模块级和参数级两种粒度都要有。**这一段你只写函数和它的测试，不登记命令**——命令是下一段的事。

**2. 库里的第 0 步标签对齐。** 前一半写的 `seed` 改成用历史模型里那个公开出来的常量（值是 `import`）。改那个常量的定义和它的两处断言。现在库里没有任何真实数据带着 `seed`，不需要迁移。

**3. 真实会话里的照片。**

- 照片对外的标识是它的通用唯一标识（一串文本）。引擎里照片到历史栈的映射，键就用它。
- **按需加载**：真实会话里，第一次用到某张照片时才去库里读它的历史、重建它的栈、放进映射。库里没有这个标识，报的是和草稿会话一样的「没有这张照片」。
- 已经加载的栈是一个缓存：每一步改动都已经提交进库了，所以缓存可以随时丢。给它一个上限（你来定，写明理由），超了丢掉最久没用的。被丢掉之后再用到，重新加载出来的和库里一致。
- 引擎的快照里「有哪些照片」，在真实会话上从库里读，不从已加载的映射读。

**4. 所有编辑、历史、处理版本号的命令，在真实会话上按 T5 落库。** `develop.set`、`develop.reset`、`develop.copy`、`develop.paste`、拖动的四个、`history.undo`、`history.redo`、`history.goto`、`process.update`：

- **先算**：在内存里算出新的栈（或新的设置）。算不出来就返回错误，这时库没被碰。
- **再提交**：一条库事务。一步的用前一半的单步接口；撤销、重做、跳转用移游标的；粘贴一批用写入器，**一批照片只在一条事务里**，要么全都成，要么全都不成。
- **再换入**：把算好的栈换进映射。这一步不许失败。
- 任何一步出错：内存和库都没变。
- 拖动：开始和中间的更新只在内存里，不落库；结束时算出最终设置，提交一步。拖到一半进程被强杀，这一步丢掉——这是计划里写明的行为。
- 拷贝到剪贴板不落库，剪贴板是内存里的东西。
- 粘贴一万张的时候，很多照片的栈还没加载过。你可以让它们走一条不必把整个栈读出来的路（只读当前设置，算出新的，写一步），只要规矩不破：步数、裁剪、照片行都和逐张加载再提交的结果一样。走不走这条路你定，在报告里说明。
- 草稿会话照旧能跑。原来那套克隆整个状态的办法，你留着它管草稿会话，或者统一成新的办法，都行；但 A7a 的每一个测试必须照旧通过，意思不变。

**5. 一个数同时盖住内存和库。** 引擎现在有一个状态的汇总值，测试和命令行拿它比「变没变」。真实会话上它要**把库里的内容也算进去**：有人只改了库没改内存，或者只改了内存没改库，它都要变。草稿会话上它的值不许变（A7a 的测试拿它比过）。

**6. 崩溃。** 用测试证明计划 §1.7 写的：在一个子进程里开会话、提交三步，再开始一次拖动并更新一下（没结束），然后让它停在那里；父进程强杀它；父进程打开同一个会话，那三步都在，游标在最新的一步，拖动的那个值不在。**只许强杀你自己刚起的那个进程。**

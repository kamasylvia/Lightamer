# Lensfun license texts

- `cc-by-sa-3.0.txt` — the CALIBRATION DATABASE's license (the data in
  `Resources/Lensfun/version_1/`; see that directory's README + NOTICE
  entry N).
- `database-CC-BY-SA-3.0.txt` — the database project's attribution
  statement.
- `lgpl-3.0.txt` — the Lensfun LIBRARY's license (Lightamer does NOT
  link the library; the text ships for completeness of the upstream
  provenance bundle, mirroring RawLab's third_party/lensfun form).

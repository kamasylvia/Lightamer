## 纪律（强制）

- **每任务独立提交**（Conventional Commits，只 add 相关文件）；`caffeinate -dis`；单测 `Scripts/test-direct.sh '<Class>'`（L019b）。
- **每任务边界检查 `.work/config.toml [gsd]` 开关（`auto`/`paused`）**——任务收尾 commit 后、下一任务开工前：`paused=true` 全链路停（在制品已 commit、工作区干净地停、报告断点）；`auto=false` 完成当前任务后停等用户「继续」。
- **L012 红线**：会话/recent 打开一律同窗路由（SessionCoordinator → EditorState 既有链），禁 WindowGroup odoc / 新窗口；UI 回归须含「连续打开 3 个会话仅 1 个 MTKView」探针级断言（单测计数形态）。
- **L013 哈希纪律**：索引 `params_hash`/`thumb_params_hash` 列一律 decimal TEXT（`UInt64String` 语义）；schema 冻结提交前 `grep -n "params_hash" SessionIndexSchema.swift` 复查非 INTEGER。

- RESEARCH 未覆盖的实现细节（SQLite 绑定精确形态/错误类型面/recent 上限内 UI 呈现细节）标注**执行期决策**入 `09-01-DECISIONS.md`，不臆造。

### T4 SessionIndexStore：libsqlite3 薄封装 + schema v1 冻结 + 开卷增量同步单事务（SESS-07 核心）

- **action**
  1. `SQLiteHandle`（Core/Session/）：`sqlite3_open_v2`（WAL）/`prepare`/`bind`（TEXT/INT/DOUBLE/NULL）/`step`/`finalize`/事务（BEGIN/COMMIT/ROLLBACK）薄封装 + typed error 面（`SessionIndexError`：open/schema/exec 三分）；actor 包装。**零新 SPM 依赖**（D-09-CONTEXT-1）；`synchronous=NORMAL` 钉死（头注写明理由——dirty 标记崩溃安全）。
  2. `SessionIndexSchema`：09-RESEARCH §2.3 草案为基线**冻结拼写**——`images` 表全列（含 `rating/color_label/keywords` Phase 12 预留列（D-09-CONTEXT-7）+ `dirty INTEGER DEFAULT 0`（9-4 消费）+ `orphan_sidecar INTEGER`）+ `meta` 表（schemaVersion/scan_epoch）+ `idx_images_dir` 索引；`params_hash`/`thumb_params_hash` **decimal TEXT**（L013）；v2 迁移位（`meta.schemaVersion` 分派，v1 恒直建）。
  3. `SessionIndexStore.openSession(root:)` 增量同步：消费 T3 扫描流 → 单事务内 `SELECT path,mtime,size` 全行 ⊕ diff → added INSERT（轻量行）/removed DELETE（含 thumbs 文件清理缝）/changed UPDATE（置轻量列重算 + thumb stale + sidecar 重读标记）→ `meta.scan_epoch++` COMMIT。**一次批量变更 = 一个事务**（纪律，9-4 批量 apply 同律）。
- **证据**：`SessionIndexStoreTests`——schema 冻结表（列名/类型/序逐列断言）；增量同步三向量（新增/删除/漂移各构造 fixture，diff 结果精确）；单事务原子性（中途注入错误 → ROLLBACK 后行集合不变）。

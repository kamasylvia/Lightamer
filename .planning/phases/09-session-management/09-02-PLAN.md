> （coalescing / 4096 批上限 / rename 丢失拆分 / 高负载丢事件——ROADMAP Notes +
> L007 + Watchexec「a mistake」结论）。设计按 **hint-only** 展开：事件只做两件事

> 集合 = 一条查询」的模型。孤儿 sidecar（`.lra` 无原片）= 索引标记 + reconcile 动作，
> **永不硬失败**（SC#2 原文 gracefully）。

## 纪律（强制）

- **每任务独立提交**（Conventional Commits，只 add 相关文件）；`caffeinate -dis`；单测 `Scripts/test-direct.sh '<Class>'`（L019b）。
- **每任务边界检查 `.work/config.toml [gsd]` 开关（`auto`/`paused`）**——任务收尾 commit 后、下一任务开工前：`paused=true` 全链路停（在制品已 commit、工作区干净地停、报告断点）；`auto=false` 完成当前任务后停等用户「继续」。
- **hint-only 红线**：FSEvents 回调**禁止**直接改索引行/删行——只允许（a）行级 stale 标记（b）入队 reconcile。rename 旧路径事件不可信：删除的行先标 stale 不物理删，reconcile diff 以 stat 裁决（「rename 幸存」路径必须有测试钉死）。
- **自反馈环防线（双防，缺一即 FAIL）**：①ignore 集共用 09-01 exclude 表单一真源（`.lightamer/**`/dotfile/`*.tmp-*`/`*.cosessiondb`）；②自家写侧吞事件——sidecar 写完成后按 path 前缀过滤自家 pending reconcile 计划（或写入方显式吞掉该路径，二选一执行期钉死入 DECISIONS）。**常驻断言：连续写 100 张 sidecar 零自触发 reconcile**。
- **孤儿永不硬失败**：orphanSidecar 行的任何处置路径不得 throw 出 UI 层；「移除 sidecar / 忽略」两动作外的文件操作（如恢复原片）禁止。
- **纯函数可测性核心**：`ReconcileDiff` 不 import FSEvents/App 层、不碰文件系统——输入 = 两次快照（扫描三元组集合 + 索引行集合），输出 = 计划值类型；一切分叉逻辑在纯函数里。
- **防空转**：diff golden 逐集合精确断言（added/removed/changed/rename 幸存/孤儿五桶计数 + 成员路径）；合成事件测试限时 await（超时 = fail）。
- fixture 在临时目录（L009）；RESEARCH 未覆盖细节（latency 精确值/事件分类枚举拼写/debounce 参数）标注**执行期决策**入 `09-02-DECISIONS.md`。

## Tasks

### T1 ReconcileDiff 纯函数（Core 级，先测后接）

- **action**
  1. `ReconcileDiff`（`LightamerCore/Sources/Session/`）：输入 `previous: Snapshot`（索引行集合）+ `current: Snapshot`（扫描三元组集合）→ 输出 `ReconcilePlan`：`added/removed/changed/renamedSurvived/orphanSidecars` 五桶值类型；changed 判定 = mtime/size 漂移；**rename 幸存裁决** = removed 候选中 mtime/size 与 added 候选精确匹配的配对 → 报 rename（路径更新保行）而非删+增；externalEdits（原片 mtime 漂移而 sidecar 未动）单独桶 → 解码缓存失效 + thumb stale 语义标记。
  2. `apply(plan:)` 腿（索引 actor 单事务更新——复用 09-01 增量同步同款事务纪律）与纯函数分离（Core 纯函数 + App 层 apply，或同文件分层——执行期决策）。
- **证据**：`ReconcileDiffTests` golden——构造前后两次快照：①纯新增 ②纯删除 ③mtime 漂移 ④**rename（mv 同内容文件）→ renamedSurvived 配对且原行不丢** ⑤`.lra` 留原片走（orphanSidecar）⑥混合场景全桶计数精确；纯函数无副作用断言（同输入两次调用同输出）。

### T2 SessionWatcher：FSEventStreamCreate 封装（hint-only）

- **action**
  1. `SessionWatcher`（App/Session/）：`FSEventStreamCreate` flags = `FileEvents | UseCFTypes | NoDefer | WatchRoot`，latency 0.3-0.5s（coalescing 窗，执行期定值），schedule 私有 serial DispatchQueue，回调 → `AsyncStream<WatchEvent>` 交 reconcile 协调者；`WatchRoot` 语义 = 会话根自身被改名/移动收到事件 → 升级全量重扫 + recent 路径失效提示（**不静默改路径**）。
  2. 事件分类（结构性，不逐文件信任）：affected 目录集 + 超阈值（>4096 路径批上限对策——事件携带目录而非逐文件；大批量直接升级全量 reconcile）。
  3. start/stop 生命周期挂 SessionCoordinator（开卷 start、切会话 stop——9-1 teardown 五步缝）。
- **证据**：`SessionWatcherTests` 合成事件——单测内起真 FSEventStream 监视临时目录（macOS 本地测试合法）：create/rename/move-out/delete 各一，事件被分类接收（限时 await）；WatchRoot 腿：临时目录 rename → 根事件到达断言。

### T3 四时点 reconcile 调度 + 自反馈环防线

- **action**
  1. `SessionReconciler`（App/Session/）：四时点——①开卷（全量，复用 09-01 增量同步）②app 获焦（`NSApplication.didBecomeActiveNotification` 强制）③FSEvents 批后（debounce 300ms，仅受影响子树——子树 diff = 全量 diff 的子集过滤，执行期决策细化）④WatchRoot/「must rescan」全量。
  2. 忽略集共用 09-01 exclude 表（单一真源引用，禁复制第二张表）；自家写侧吞事件（sidecar 写完成后按 path 过滤 pending 计划——执行期二选一钉死）。
  3. **自反馈环常驻断言**：测试内连续写 100 张 sidecar（真实 `writeAtomic` 路径）→ 观察窗内 reconcile 自触发计数 == 0（watcher 在跑的前提下）。
  4. 行级 stale 标记：事件到达 → 对应行 `thumb_state`/轻量列置 stale（**不删行**——rename 旧路径事件不可信），等待 reconcile 裁决。
- **证据**：`SessionWatcherTests` 自反馈环断言绿；获焦/事件批后/debounce 时序单测（注入时钟或短窗实测，执行期决策）；exclude 单一真源断言（watcher 与 scanner 引用同一常量——编译期同源 + 测试值比对）。

### T4 孤儿 sidecar 处置 + 状态行接线（SESS-05 edge case）

- **action**
  1. orphanSidecar 行 UI：grid cell 孤儿徽章（9-3 接视觉，本 plan 出状态与数据缝）+ reconcile 动作入口（侧栏会话区或上下文菜单——**「移除 sidecar / 忽略」两选项**；移除 = 删 `.lra` 文件 + 索引行清理，确认弹窗防误触；忽略 = 行级 ignore 标记持久化到索引）。
  2. `folderWatchStatus` 接真源：watching/scanning/synced/stale/rootLost 五态（stub 字段转正式枚举）；rootLost（WatchRoot 触发）→ 状态行提示 + recent 路径失效标记。
  3. 外部改原片（externalEdits 桶）：解码缓存失效 + thumb stale + 索引行 sidecar 重读标记（为 9-3/9-4 的再生管线供缝）。
- **证据**：`SessionReconcileE2ETests`——FileManager 模拟 Finder 外部变更（新增/删除/移动/内容改写）→ reconcile 后索引集合与磁盘**精确**一致；move-out 后 rename 幸存自愈（rename 丢失场景钉死：旧路径 stale 行被 reconcile 收敛为 renamedSurvived，不丢单不重复）；孤儿处置两动作各一 case（移除后 `.lra` 确实不在磁盘 + 忽略后行稳定）。

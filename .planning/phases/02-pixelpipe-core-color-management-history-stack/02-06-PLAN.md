# Plan 02-06 — Sidecar persistence + clearCaches + memory harness + RAW-03 + Phase 2 sign-off

## Goal

Close the phase: persist the history stack (HIST-03), enforce the memory budget (D-C1/D-C2 — spike-b measured 4.3-5.4GB cross-decode accumulation without it), land RAW-03, and run the Phase 2 sign-off against ROADMAP SC#1..5.

1. **Sidecar `.lra`** (D-S1/S2/S3): JSON (Codable, pretty-printed, `schemaVersion: 1` from day one), `<原文件完整名>.lra` beside the original (`DSC09991.ARW.lra`), `.xmp` completely ignored. `SidecarStore` actor: 2-second throttled merge-writes (slider storms never hit disk), atomic write (same-directory tmp + `FileManager.replaceItemAt` — L009: same-volume rename or atomicity is lost), `flush()` on image switch + `applicationWillTerminate`. **imageID persistence**: first open mints the image's UUID into the sidecar; cache keys and instance references reuse it forever after. **Drift detection (HIST-04/SC#5)**: stored `historyHash` vs `HistoryHash.hash(stack:)` recomputed at load — mismatch = log + status-bar toast (D-26), in-memory state wins, **never auto-rewrites**. **Unknown-op safety**: `ModuleRegistry.makeBox` nil → instance preserved verbatim (`paramsData` untouched), `enabled=false`, toast — user data is never dropped (research Risk #10).
2. **clearCaches (D-C1/D-C2)**: `PipeCache.enforceBudget(keeping:)` — pure policy executor (evict order: other-image THUMBNAIL/EXPORT → other-image FULL → other-image PREVIEW except the most recent → lastly current-image inactive resolutions; research §6) + `CIContextPool.clearCaches()` (`ciContext.clearCaches()` — the CI/RawCamera internal state that spike-b flagged as an accumulator). Triggers in `PipeCoordinator`: every `load` entry (synchronously, BEFORE the new decode) + a 60-second `Task.sleep` loop (actor-internal, not Timer/RunLoop — research Open Question #7: timer is only a caller; `enforceBudget` is unit-testable pure). Toast throttled: one notification when freed > 500MB.
3. **RAW-03**: 32-bit float TIFF/EXR/HIF read as HDR/stack sources. ImageIO advertises the UTIs (research §7: verified `com.ilm.openexr-image`/`public.tiff`/`public.heic` on this host); the open question is bit-depth preservation through `CGImageSourceCreateImageAtIndex`. Fixture-driven tests pin the behavior; if CGImage downgrades float, the fallback is `CIImage(contentsOf:)` (CI's own float-native loader). HDR values >1.0 must survive into the float32 pipe (D-COL4: clamp only at gamma).
4. **Sign-off**: full suite green; `02-VALIDATION.md` completed (map statuses + `nyquist_compliant: true` + approval); ROADMAP SC#1..5 checked one by one; TODO.md Phase 2 status updated (§3.1 doc-sync rule).

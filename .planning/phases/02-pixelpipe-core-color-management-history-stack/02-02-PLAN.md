# Plan 02-02 — process texture migration + TestGain + PipeCache + PixelPipe.processRec (the SC#2 fast path)

## Goal

Land the heart of FOUND-04: the Darktable recursive pixelpipe with a per-module per-ROI cache and the hash-chain hit fast path (SC#2's mechanism — "dragging a parameter invalidates only modules at or after the changed module"). Four moves:

1. **`IOPModule.process` signature migration: `MTLBuffer` → `MTLTexture` in/out** (RESEARCH §1.4, Open Question #1 — RECOMMENDED and adopted here). Textures are the pipe's currency (cache planes, `displayTexture`, PREVIEW/FULL are all textures; `dispatch2DTexture` exists); the Buffer shape was a Phase 1 spike artifact bridged by an ugly buffer↔texture staging in PassthroughModule. Migrating NOW, before a second module exists, is the cheapest moment — it locks the public contract every Phase 3+ iop conforms to.
2. **`TestGainModule`** (LightamerIOP, dev-only `#if DEBUG`) — a one-parameter gain module that is SC#2's demonstration vehicle (research: "此模块是 SC#2 的必要道具"): the cache tests change its params and assert partial hits. Phase 2 has no real sliders; this module is the first param change to flow through the pipe.
3. **`PipeCacheKey` + `PipeCache`** — the Swift translation of Darktable's cache-line hash (`pixelpipe_cache.c:99-172`) and byte-budget LRU pool (`:174-354`), simplified: a dictionary-keyed actor needs no fixed cacheline pool, no aging counters, and no size-mismatch dirtying (research Risks/design notes). Hit/miss counters + signposts are the SC#2 verification channel.
4. **`PixelPipe.processRec`** — the recursive walk (`pixelpipe_hb.c:1838-1999`): skip disabled pieces, incremental `upstreamHash` combine, cache-probe → miss-closure (recurse upstream, run module, store plane). `decodeParamsHash` is mixed in at position 0 from day one (§1.3 gotcha — prevents silent Phase 3 "WB change does nothing" cache staleness). FULL-pipe policy: NO per-module intermediate caching (100MP plane multiplication explodes the 4GB budget — spike-b evidence; only PREVIEW/THUMBNAIL cache per-module; see checkpoint).

The identity/erasure seam: `associatedtype Params` means `any IOPModule` cannot form (Phase 1 gotcha), so the pipe drives modules through a type-erased `ModuleBox<M>` (Core) — also the object the Phase 2 history/coordinator layer materializes from `ModuleRegistry` (02-04) and `effectiveInstances()` (02-05).

## Tracer vertebra mapping

Wave 2. After 02-01 the display path is single. After 02-02 the pipe actually *processes*: `decoded CIImage → input plane → [pieces in v50 order with cache] → output plane`. SC#2's cache semantics are provable headlessly (run1 all-miss / param change → partial hit / undo → full hit) using a terminal-free module chain — the full `[colorin, testGain, colorout, gamma]` chain variant runs in Plan 02-04's harness once the terminal trio exists.

## Must-haves (goal-backward verification)

- [ ] `IOPModule.process` signature is `process(input:any MTLTexture, output:any MTLTexture, roiIn:ROI, roiOut:ROI, piece:inout IOPiece, metal:MetalContext) async throws`; `IOPiece.paramsHash` is `UInt64`; PassthroughModule + `pass_through` kernel migrated to textures; no `MTLBuffer` remains in the protocol (grep).
- [ ] `TestGainModule` is `public final class` in `LightamerIOP`, guarded `#if DEBUG`, `Params { var gain: Float }`, `opName "testgain"`, `iopOrder 50.5`; `test_gain` kernel multiplies RGB by gain in linear float32.
- [ ] `PipeCacheKey` (internal, Core/Pipe): `(imageID: UUID, pipeType: PipeResolution, position: Int, upstreamHash: UInt64, roi: ROI)`. `PipeResolution` enum (`preview/thumbnail/full/export`) lands here (public, Codable — Plan 02-03 grows the lifecycle around it).
- [ ] `PipeCache` is an `internal actor` with byte-budget LRU (default 3 GB constructor constant, evict-to-2GB hysteresis), `totalBytes`, hit/miss counters (`CacheStats`), signpost `cache HIT/MISS`, `invalidate(imageID:)`, `@unchecked Sendable CachedPlane`.
- [ ] `PixelPipe.processRec(position:roiIn:...)` implements: disabled-skip → incremental upstreamHash → cache probe → miss closure (recurse position-1 → `piece.process`) → store. `decodeParamsHash` mixed into position-0 keys. Pass-through-era ROI identity asserted (research Risk #7 invariant). FULL pipes bypass intermediate caching by policy.
- [ ] `PipeCacheTests` green: run1 all-miss; change TestGain params → upstream hit + downstream miss; undo → all hit; eviction keeps `totalBytes` ≤ budget under oversubscription.
- [ ] Update `LightamerCore/API.md` + `LightamerIOP/API.md` (D-03c — same-batch rule).

## Reversibility gates (one-way / costly decisions)

- **`IOPModule.process` signature (Buffer→Texture) — COSTLY/one-way.** Public protocol; every future iop conforms to it. Locked by checkpoint task 02-02-01 before any migration edit.
- **`PipeCacheKey`/hash scheme (D-H4 shared FNV-1a) — COSTLY.** Cache identity must equal history identity's atom (`paramsHash`) or sidecar drift detection (02-06) silently disagrees with cache invalidation. Locked in the same checkpoint.
- **FULL-pipe no-intermediate-cache policy — COSTLY (performance architecture).** Reversing it later = memory-budget redesign. Locked in the checkpoint with spike-b numbers on record.

## Task 02-02-01 — checkpoint:decision (process signature, cache key/hash scheme, per-pipeType cache policy)

**kind:** checkpoint:decision

**read_first:**
- `.planning/phases/02-pixelpipe-core-color-management-history-stack/02-CONTEXT.md` — D-H4 (paramsHash FNV-1a shared with PipeCacheKey), D-C3 (pipe resolution buckets), "the agent's Discretion" (recursion/ROI/hash details delegated to planner)
- `.planning/phases/02-pixelpipe-core-color-management-history-stack/02-RESEARCH.md` — §1.1 (Darktable hash composition, file:line), §1.2 (Swift PipeCacheKey/PipeCache/processRec), §1.3 (decodeParamsHash gotcha), §1.4 (Buffer→Texture recommendation), Risks #2/#3/#6/#7
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/spike-b-100mp-perf.md` — §4 (plane multiplication ≈ 4.7GB for 3 FULL planes → the FULL-cache ban evidence)
- `LightamerCore/Sources/Pipe/IOPModule.swift`, `IOPiece.swift`, `PixelPipe.swift` — the surfaces being changed

**decision:** Confirm before 02-02-02 touches the protocol:
1. **process → textures:** `process(input: any MTLTexture, output: any MTLTexture, roiIn: ROI, roiOut: ROI, piece: inout IOPiece, metal: MetalContext) async throws`. `IOPiece.data` stays `MTLBuffer?` (uniforms). PassthroughModule + kernel migrate in the same task batch (no compile window with mixed signatures). COSTLY.
2. **`IOPiece.paramsHash: Int` → `UInt64`** — one type for cache identity and history identity (D-H4); computed by modules as `StableHash.hash(encoded params)` in `commitParams`. COSTLY.
3. **`PipeCacheKey` = `(imageID, pipeType, position, upstreamHash, roi)`** where `upstreamHash` = incremental `StableHash.combine` over enabled pieces' `paramsHash` for all positions < `position`, seeded with `decodeParamsHash` at position 0. `position` is chain index (NOT iop_order — `pixelpipe_cache.c:113` note). ROI in key at pass-through era is constant per pipe — asserted, not exploited (Risk #7 invariant; Phase 4 exercises real ROI negotiation).
4. **Per-pipeType cache policy:** PREVIEW + THUMBNAIL → per-module caching ON; FULL → input plane cached, intermediates ping-pong uncached (spike-b: 3 planes ≈ 4.7GB > 4GB budget); EXPORT → no cache (Darktable parity, `pixelpipe_hb.h:346-355`). Encoded as `PipeResolution.cachesIntermediatePlanes: Bool` + processRec branch. COSTLY.
5. **`PipeCache` eviction:** LRU by `lastHit`, byte budget 3GB (D-C1 constant `PipeCache.defaultBudget`), hysteresis evict-to-2GB (`0.66 × budget`); no Darktable cacheline pool / aging / size-dirty machinery (dictionary keys make it structurally unnecessary — research §1.2).
6. **`ModuleBox<M: IOPModule>`** (Core, public final class) is the type-erased pipe citizen: `instanceID`, `opName`, `multiPriority`, `multiName`, `iopOrder`, `enabled`, `paramsData: Data`, `paramsHash: UInt64`, `func processErased(input:output:roiIn:roiOut:metal:) async throws` (dispatches into the concrete module with committed `IOPiece`). The pipe walks `[Piece]` = `(box, pieceState)`. History (02-05) materializes boxes from `ModuleInstance` via `ModuleRegistry` (02-04).
7. **Texture contract:** cached/stored planes are written-once-then-read-only (`usage = [.shaderRead, .shaderWrite]` during processing; cache stores planes produced as outputs), handed across actor boundaries only via `@unchecked Sendable` wrappers with the Phase 1 `RenderedTexture` ownership contract (Risk #6). Ping-pong scratch planes are pipe-private, never cached.
8. **TestGain placement:** `LightamerIOP`, `#if DEBUG` whole-file, `opName "testgain"`, `iopOrder 50.5` (free slot between colorin 28.0 and colorout 70.0; collision with passthrough's 50.5 is legal — Darktable has deliberate order collisions). NOT registered in any default chain (registered for tests only, 02-04's registry populates IOP modules explicitly).

**acceptance_criteria:**
- This checkpoint is marked done before 02-02-02 starts; the eight locks are affirmed in the execution log.

**action:** No file change. Explicit gate; escalate if any lock is contested.

# Plan 03-06 — filmicrgb + variants + PERF-5 + Phase 3 签核

## Goal

攻坚 ROADMAP 标注的**最难单移植** filmicrgb（IOP-FILM-01，~2000 行 scene-linear 数学）——按 D-T1 分解为 F0-F4 五个可独立 golden 验证的子阶段（RESEARCH §2.2）。随后交付 IOP-FILM-03（filmic 变体 = **agx**，与 sigmoid 共享 per-channel primaries 基建）与 PERF-5 正式 CI 记录，最后执行 Phase 3 VALIDATION 签核（ROADMAP §Phase 3 四条 SC 逐条核对）。

**结构前提（RESEARCH §2.1）**：filmicrgb 全部难点无一处需要局部归约或邻域访问（高光重建除外，默认关闭）——「CPU 样条推导 + 逐像素管线」可拆成 golden 可测子阶段。

**输入语义 caveat（同 03-04）**：算法 parity 用合成场景线性 EXR fixture（两侧同输入）；真机 RAW 上 displayed-domain 默认值校准（black −8EV/white +4EV/grey 18.45% 假设场景线性）是独立产品语义任务，与 parity 解耦（模块头注记）。

## Must-haves

- **checkpoint:decision（D-T1 范围定稿，见 T0）**
- F0 CPU 推导单测（M1..M5 float4×5、output_power、norm_min/max——`compute_spline` v3 + `_compute_output_power` + norm 界直译）
- F1 三方对照：CPU LUT vs Metal kernel 采样 vs dt-cli 单模块（10001 点，<1e-6）
- F2 V5 双路混合 + F3 Yrg gamut 映射各自独立 fixture golden
- F4 全模块 torture EXR 组 parity
- **colorscience 只落 V5**（V1-V4 不移植，params 枚举保留位）；preserve_color norm 家族全实现（MAX_RGB 固定用于 V5）；高光重建子树仅 mask kernel + 参数位（F5 重建挂 TODO）
- agx（IOP-FILM-03）：params + `kernel_agx` 直译，共享 sigmoid primaries 基建；「hatchless」记录为无对标不实现
- PERF-5：PREVIEW 全模块链单帧 <16.6ms CI 记录 + PSO 启动预热 + FULL toneequal 100MP <3GB 复验
- Phase 3 VALIDATION 签核：`03-VALIDATION.md` 全行 ✅ + `nyquist_compliant: true` + ROADMAP SC#1-4 核对

# Plan 03-01 — Wave 0 基建 + exposure（tracer plan）

## Goal

打通 Phase 3 全部 golden 验收基建（RESEARCH §6），并用最简单的 exposure 模块（LightamerIOP public）（IOP-TONE-01）证明 parity 轨全链路可行。**Tracer = "exposure parity green"**：本 plan 完成即证明 dt-cli 参考生成 → fixture → Lightamer 管线 → 逐像素比对的整条验收链可信，后续 5 个 plan 直接复用本 plan 的一切产物。

RESEARCH §6.2 实测：预构建 darktable-cli（1263552fab-dirty）丢 XMP 历史 → **重建是硬前置**，不重建则 D-T5 整条 golden 线不可用。

## Must-haves

- darktable-cli 从当前源码树（dc58cf0ba1）重建成功，XMP 钉参链路实测被采纳（+1EV 输出实际变化）
- `input/golden/regenerate.sh` 一键复现全部 fixture + golden 输出 + manifest
- `GoldenParityTests` 双轨 harness（轨 A dt-cli fixture parity / 轨 B Phase 2 双判据回归）可被后续模块直接复用
- `CPUDerivationTests` 框架（公式直译 + 已知向量，不依赖 dt 二进制）
- exposure `.swift + .metal` 文件对注册进 ModuleRegistry（v50 位次 21.0），parity <1e-5
- 有意 divergence 全部记录在模块头注释：默认 0EV（非 dt 0.7EV）、deflicker 不实现（mode 位保留）、processed_maximum 不跟踪（RESEARCH Risk #6）

# Plan 01 — App Skeleton (tracer vertebra: "app launches and shows empty shell")

## Goal

Stand up the greenfield macOS 27 app from an XcodeGen `project.yml`: the `Lightamer` application target with macOS 27 deployment target, Swift 6 strict concurrency, single app target + subsystem source directories, locked Bundle ID `com.kamasylvia.lightamer`, and the three-column `NavigationSplitView` shell (sidebar / editor area / inspector) with forced dark mode, empty-state prompt, top toolbar, and menu bar. This is the leading tracer slice — "the app launches and shows an empty shell" — into which Plans 02-04 plug RAWDecoder, MetalContext, the MTKView viewport, and the pixelpipe skeleton.

It also lands the two cross-cutting foundational types every later plan depends on: `AppError` (D-25, the typed cross-layer error enum) and `WorkingSpace` (FOUND-02: linear Rec2020 scene-referred float32 RGBA constants).

## Tracer vertebra mapping

This plan is Wave 1 plan #1. It produces the *shell* half of the Phase 1 vertebra ("open a RAW and see it on screen"): an app that launches, shows the three-column chrome with an empty editor area, and is ready to receive a `RAWDecoder` (Plan 02) + `EditorMTKView` (Plan 03). The vertebra is completed by Plan 03's task that wires `EditorState.load(url:)` to the `EditorMTKView` in the center column.

## Must-haves (goal-backward verification)

- [ ] `xcodebuild build -project Lightamer.xcodeproj -scheme Lightamer -destination 'platform=macOS'` exits 0 on the macOS 27 SDK.
- [ ] `Lightamer.app` launches (via `open` or Xcode Run) without crashing; the three columns are visible.
- [ ] Dark mode is forced regardless of the system appearance setting (D-10).
- [ ] The empty-state prompt ("选择文件夹创建 Session" / "拖放 RAW 到此") is shown in the editor area when no image is loaded (D-11).
- [ ] Bundle ID is exactly `com.kamasylvia.lightamer` (D-05, one-way — set once, never changed).
- [ ] `AppError` is an enum conforming to `Error & LocalizedError` with cases covering RAW/Metal/Memory/Cancelled tiers (D-25).
- [ ] `WorkingSpace` exposes the linear Rec2020 `CGColorSpace` and the float32 RGBA pixel format constant (FOUND-02).
- [ ] Top toolbar and menu bar exist with at minimum File → Open and View menu entries (D-12).
- [ ] `.pbxproj` is NOT committed; `project.yml` is the source of truth (D-01).

## Reversibility gates (one-way / costly decisions)

- **D-05 (Bundle ID `com.kamasylvia.lightamer`) — ONE-WAY.** A `checkpoint:decision` task precedes the project.yml task that sets `PRODUCT_BUNDLE_IDENTIFIER`. Once the app is signed/notarized/distributed, the Bundle ID is immutable.
- **D-07 (three-column NavigationSplitView) — COSTLY.** The three-column shell is the SwiftUI骨架; changing it later ripples through every child view. Locked by checkpoint before ContentView is written.
- **D-33 (Swift Concurrency / Swift 6 strict concurrency) — ONE-WAY (project-wide).** `SWIFT_STRICT_CONCURRENCY: complete` is set in project.yml; the concurrency model permeates all later code. Locked by the same checkpoint as D-05 (they are both project.yml one-time settings).
- **D-25 (AppError typed enum) — COSTLY (cross-layer contract).** The error type is the contract every layer throws through; changing it rewrites every catch site. Locked by the Plan 01 checkpoint before `AppError.swift` is written.
- **D-35 (`@Observable` macro for state management) — COSTLY (permeates all views).** Replaces `ObservableObject`; reverting means rewriting every `@State`/`@Environment` owner. Locked by the Plan 01 checkpoint before `AppState`/`EditorState` are written.

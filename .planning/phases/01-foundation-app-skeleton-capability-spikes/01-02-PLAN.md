# Plan 02 — RAWDecoder (LightamerCore/Decode): CIRAW 9 + unified entry + metadata + cancellable async decode

## Goal

Land the decode layer of the Phase 1 vertebra inside `LightamerCore/Sources/Decode/`: the `RAWDecoder` actor (D-21) wrapping `CIRAWFilter` with RAW 9 opt-in + RAW 8 auto-fallback (D-22), the `DecodedImage` value type, the three metadata structs (D-23: `CaptureMetadata`, `RAWTechnicalParams`, segmentation matte via `CIImage?`), and the **unified RAW + non-RAW entry** (D-24: RAW UTIs → CIRAWFilter; raster UTIs JPEG/HEIC/PNG/WebP/TIFF/PSD-flat → CGImageSource). All decode types are `public` (consumed cross-module by the app's `EditorState` and by `LightamerTests`); the `CIRAWFilter` instance, `rawUTIs`, and `decodeRaster`/`decodeRAW`/`readCaptureMetadata` helpers are `internal` to Core. The decode is `async throws`, cancellable (D-34), and runs off-MainActor. `EditorState.load(url:)` (from Plan 01) is wired to call `RAWDecoder.decode(_:)`.

This plan + Plan 03 (MetalContext + EditorMTKView) together complete success-criterion #1: "open a CR3/NEF/ARW RAW via CIRAW 9 and display it." Plan 02 produces the `DecodedImage` (a `CIImage` + metadata); Plan 03 renders it to an `MTLTexture` via `MetalContext` + `CIContextPool` and blits it through `EditorMTKView`.

## Tracer vertebra mapping

Wave 1 plan #2. Produces the *decode* half of the vertebra: a `public` `RAWDecoder` whose `decode(_:)` returns a `DecodedImage` the app can hand to the render path. Plan 01's `EditorState.load(url:)` stub is replaced here with a real decode call; Plan 03 consumes the `DecodedImage.ciImage`.

## Must-haves (goal-backward verification)

- [ ] `RAWDecoder` is a `public actor` in `LightamerCore/Sources/Decode/RAWDecoder.swift` with `func decode(_ url: URL) async throws -> DecodedImage` (D-21).
- [ ] RAW 9 opt-in: under `#available(macOS 27, *)`, the decoder requests `decoderVersion = .version9`; if the file's `supportedDecoderVersions` does not include 9, it silently falls back to `.version8` (D-22, RAW-05). `DecodedImage.decoderVersionUsed` records which was used.
- [ ] Unified entry (D-24, RAW-04): RAW UTIs (CR3/NEF/ARW/RAF/RW2/ORF/PEF/RWL/3FR/IIQ/DNG/X3F) route to `decodeRAW` (CIRAWFilter); raster UTIs (JPEG/HEIC/PNG/WebP/TIFF/PSD-flat) route to `decodeRaster` (CGImageSource). The branching is internal; callers see one `decode(_:)`.
- [ ] Adobe DNG (RAW-02) decodes via the RAW path (UTI `public.adobe-dng`).
- [ ] Three metadata classes (D-23, RAW-06): `CaptureMetadata` (EXIF/IPTC/XMP — camera/lens/focal/aperture/shutter/ISO/GPS/capture-time), `RAWTechnicalParams` (black/white level, baseline exposure, neutral chromaticity), and segmentation sky matte (`CIImage?` — iPhone ProRAW only, nil for DSLR).
- [ ] Decode is `async`, runs off-MainActor, and is cancellable (D-34): `Task.cancel()` on a decode aborts it (via `withTaskCancellationHandler` wrapping the CIRAW decode).
- [ ] A corrupt/truncated RAW fails with a typed `AppError` (D-25), not a crash.
- [ ] `EditorState.load(url:)` calls `RAWDecoder.decode(_:)` and stores the `DecodedImage`; the decode is wrapped in `os.signpost` intervals (D-31).

## Reversibility gates (one-way / costly decisions)

- **D-21 (`RAWDecoder` public interface + location in Core/Decode) — ONE-WAY.** `RAWDecoder.decode(_:)` is the pixelpipe's input contract; once the app + tests depend on it, changing the signature or relocating the type is a cross-module migration. A `checkpoint:decision` task precedes writing `RAWDecoder.swift`.
- **D-22 (RAW 9 default + auto-fallback strategy) — REVERSIBLE** but the `decoderVersionUsed` field on `DecodedImage` is part of the public surface and should be stamped into sidecars (Phase 2) from day one (per RESEARCH §2 ⚠ DECISION REVIEW — reserve the sidecar field now even though sidecars are Phase 2).
- **D-23 (three metadata classes) — COSTLY.** The metadata struct shapes are the InspectorState display contract and the Phase 2 sidecar schema. Locked by checkpoint.

## Task 01-02-03 — RAWDecoder (public actor): unified entry, RAW 9 opt-in, raster fallback, cancellable decode

**read_first:**
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-RESEARCH.md` — §2 (full `RAWDecoder` skeleton; `CIFilter(imageURL:options:)` entry; `kCIInputDecoderVersionKey` / `RawDecoders.version9`; `kCISupportedDecoderVersionsKey` read-only gotcha — probe on a scratch filter; RAW 9 no-op keys per WWDC26/305; `kCIInputSemanticSegmentationSkyMatteKey` for iPhone ProRAW; two-instantiations-per-decode cost + LRU cache recommendation; `kCIInputAllowDraftModeKey` for thumbnails; `kCIInputEnableVendorLensCorrectionKey` defaults true; DNG "just works")
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-CONTEXT.md` — D-21, D-22, D-24, D-33, D-34
- The `AppError` type from Plan 01 (the error bridge — same module, no import needed)
- The metadata structs from 01-02-02

**action:** Create `LightamerCore/Sources/Decode/RAWDecoder.swift`:

- `public actor RAWDecoder` (D-33 actor; Open Question #1 — actor over `@unchecked Sendable` class).
- `public func decode(_ url: URL) async throws -> DecodedImage` — `nonisolated` so it runs off-MainActor. Implementation:
  1. Determine UTI via `CGImageSourceCreateWithURL` + `CGImageSourceGetType` (default `public.data`).
  2. If UTI ∈ `Self.rawUTIs` → `try await decodeRAW(url)`; else → `try decodeRaster(url, uti:)`.
  3. Wrap the CIRAW decode body in `withTaskCancellationHandler` (D-34) and check `Task.isCancelled` after each await; throw `AppError.cancelled` if cancelled.
  4. Wrap the whole decode in an `os.signpost` interval (`OSSignposter(subsystem: "com.kamasylvia.lightamer", category: "decode")`, D-31).
- `internal func decodeRAW(_ url: URL) async throws -> DecodedImage`:
  1. Build a probe `CIFilter(imageURL: url, options: [:])`; read `supportedDecoderVersions` (read-only key — RESEARCH §2 gotcha).
  2. Under `#available(macOS 27, *)`: if the probe reports version 9 support, set `kCIInputDecoderVersionKey` to `CIFilter.RawDecoders.version9` (typed enum if exposed in the macOS 27 SDK; else the string `"9"` per RESEARCH §2 gotcha #4); else fall back to `.version8`. Below macOS 27: `.version8`.
  3. Build the real `CIFilter(imageURL:options:)` with the chosen decoder version. Leave `kCIInputEnableVendorLensCorrectionKey` at default true (Phase 4 for manual lens iop). Do NOT set RAW 9 no-op keys.
  4. Read `outputImage` → `CIImage` (throw `AppError.decodeFailed` if nil).
  5. Read RAW technical params (D-23b): `blackLevel`, `whiteLevel`, `baselineExposure`, `neutralChromaticity` via the corresponding `CIRAWFilterOption` keys.
  6. Read `kCIInputSemanticSegmentationSkyMatteKey` → `CIImage?` (nil for non-ProRAW — L004).
  7. Read capture metadata via `readCaptureMetadata(url:)` (D-23a).
  8. Return `DecodedImage(ciImage:rawTech:capture:segmentationSkyMatte:decoderVersionUsed:)`.
- `internal func decodeRaster(_ url: URL, uti: String) throws -> DecodedImage` (RAW-04):
  1. `CGImageSourceCreateWithURL` with `kCGImageSourceShouldCache: false`.
  2. `CGImageSourceCreateImageAtIndex(_, 0, nil)` → `CGImage`; build a `CIImage(cgImage:)`. (Multi-image TIFF → first image only per RESEARCH edge cases.)
  3. `rawTech` = a default/empty `RAWTechnicalParams` (raster has no RAW technical params); `segmentationSkyMatte` = nil; `decoderVersionUsed` = `.v8` (n/a for raster but the field is non-optional).
  4. Read capture metadata via `readCaptureMetadata(url:)`.
- `internal static func readCaptureMetadata(url: URL) throws -> CaptureMetadata` (D-23a, RAW-06): `CGImageSourceCreateWithURL` (`kCGImageSourceShouldCache: false`), `CGImageSourceCopyPropertiesAtIndex(_, 0, nil)`, walk `kCGImagePropertyExifDictionary` / `kCGImagePropertyExifAuxDictionary` (lens!), `kCGImagePropertyTIFFDictionary` (Make/Model), `kCGImagePropertyGPSDictionary`, `kCGImagePropertyIPTCDictionary`, `kCGImagePropertyXMPDictionary`. Parse EXIF date strings. Map `kCGImagePropertyOrientation` 1..8.
- `internal static let rawUTIs: Set<String>` — the RAW-01 UTI list (Canon CR2/CR3, Nikon, Sony, Fuji, Panasonic RW2, Olympus, Pentax, Leica RWL, Hasselblad 3FR, Phase One IIQ, Adobe DNG, Sigma X3F). `internal` — not part of the public API.
- A small internal LRU keyed on `(url, mtime)` caching the probe's `supportedDecoderVersions` result (RESEARCH §2 gotcha: two instantiations per decode; the probe result is per-file stable).

On any decode failure (nil output, unreadable file, IO error), throw the appropriate `AppError` case (`.unsupportedFile`, `.fileUnreadable`, `.decodeFailed`) — never a raw `CIFilter` exception (D-25).

**acceptance_criteria:**
- `RAWDecoder.swift` contains `public actor RAWDecoder` and `public func decode(_ url: URL) async throws -> DecodedImage`.
- The file contains `#available(macOS 27, *)` gating the RAW 9 path (RAW-05, L001).
- The file contains `withTaskCancellationHandler` wrapping the CIRAW decode (D-34) and a `Task.isCancelled` check.
- The file contains `Self.rawUTIs` with at least: `public.canon-cr3`, `com.nikon.raw-image`, `com.sony.raw-image`, `com.fuji.raw-image`, `com.panasonic.rw2-image`, `com.olympus.raw-image`, `public.adobe-dng` (RAW-01/02).
- The file contains the raster path (`decodeRaster`) handling the JPEG/HEIC/PNG/WebP/TIFF branches (RAW-04).
- `RAWDecoder.swift` references `AppError` (same module — `LightamerCore/Sources/Foundation/AppError.swift`).
- The `CIRAWFilter` instance is `internal` (never exposed in a `public` property or return type).
- An `os.signpost` interval wraps the decode (D-31).
- Compiles under Swift 6 strict concurrency with no data-race warnings (the actor isolation is correct; `CIFilter` is freshly instantiated per decode).

# Plan 02 — RAWDecoder (tracer input half: "any RAW → CIImage + metadata")

## Goal

Implement the `RAWDecoder` — a Swift Concurrency `actor` wrapping `CIRAWFilter` that takes a file URL and produces a `DecodedImage` (CIImage + three metadata classes). It honors D-21 (RAWDecoder is the pixelpipe input contract), D-22 (RAW 9 opt-in + RAW 8 fallback via `supportedDecoderVersions`), D-23 (three metadata tiers: capture EXIF/IPTC/XMP/GPS, RAW technical params, segmentation matte), D-24 (unified RAW/non-RAW entry — JPEG/HEIC/PNG/WebP/TIFF/PSD-flat route through `CGImageSource`), D-33/D-34 (async, off-MainActor, cancellable), and the FOUND-02 working-space lock (linear Rec2020).

It also lands `EditorState` (@Observable @MainActor) — the per-editor sibling to Plan 01's `AppState` — which owns the decode `Task`, cancellation, signposted timing, and the @Observable `image` property Plan 03's `EditorMTKView` binds to. Wiring File → Open to `EditorState.load(url:)` completes the "input" half of the Phase 1 vertebra; Plan 03 completes the "display" half.

## Tracer vertebra mapping

This plan delivers the input side of "open a RAW → see it on screen": URL in → `DecodedImage` out, asynchronously, cancellably, with metadata. Plan 03 consumes `EditorState.image` to render. After this plan, `EditorAreaView` can call `editorState.load(url:)` on File → Open and the decoded `CIImage` is available (it just isn't on screen until Plan 03).

## Must-haves (goal-backward verification)

- [ ] `RAWDecoder.decode(_ url: URL) async throws -> DecodedImage` succeeds for at least one CR3, NEF, ARW, RAF, DNG (RAW-01/02) and one JPEG, HEIC, PNG, WebP, TIFF (RAW-04).
- [ ] A camera that supports RAW 9 reports `decoderVersionUsed == .v9` under `#available(macOS 27, *)`; a camera without RAW 9 silently falls back to `.v8` (RAW-05, D-22).
- [ ] `CaptureMetadata` reads camera make/model, lens model, focal length, aperture, shutter speed, ISO, capture time, GPS from at least one CR3 and one NEF (RAW-06).
- [ ] `RAWTechnicalParams` exposes blackLevel/whiteLevel/baselineExposure/neutralChromaticity/noiseReductionAmount (D-23b, for Phase 2 color management).
- [ ] `semanticSegmentationSkyMatteImage` is read when present (iPhone ProRAW) and silently nil for DSLR/Mirrorless RAW (D-23c, L004).
- [ ] Decode of a corrupt/truncated RAW throws `AppError.decodeFailed` (D-25), not a crash.
- [ ] `EditorState.load(url:)` runs decode off MainActor, is cancellable (second load cancels the first), and hops back to MainActor to set `image` (D-33/D-34).
- [ ] `os.signpost` interval `"decode"` wraps the decode call (D-31).
- [ ] `WorkingSpace.colorSpace` (linear Rec2020) is the CIContext working color space (FOUND-02).

## Reversibility gates

- **D-21 (RAWDecoder interface: URL → DecodedImage) — ONE-WAY.** This is the pixelpipe input contract; every Phase 2+ module depends on `DecodedImage`'s shape. A `checkpoint:decision` precedes the implementing task. Once `RAWDecoder.decode` and `DecodedImage` ship, changing the signature rewrites the pixelpipe.

## Task 01-02-01 — checkpoint:decision (D-21 RAWDecoder interface, D-22 RAW 9 strategy, D-23 metadata tiers, D-24 unified entry)

**kind:** checkpoint:decision
**read_first:**
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-CONTEXT.md` — D-21, D-22, D-23, D-24
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-RESEARCH.md` — §2 (CIRAWFilter instantiation, RAW 9 opt-in, supportedDecoderVersions probe, no-op keys under RAW 9, semanticSegmentationSkyMatteImage iPhone-only), §6 (ImageIO metadata, lens in ExifAux), Open Question #1 (actor vs class)
- `LESSONS.md` — L001 (RAW 9 = macOS 27), L004 (segmentation matte iPhone-only)

**decision:** Lock the RAWDecoder contract before writing `RAWDecoder.swift`:
1. **D-21:** `actor RAWDecoder` with `func decode(_ url: URL) async throws -> DecodedImage` — the single public entry. Actor isolation (not `@unchecked Sendable` class) per RESEARCH §8 Open Question #1 recommendation (Swift 6 favors actor; decode latency dominates actor hops). One-way.
2. **D-22:** Probe `supportedDecoderVersions` once per file; if it contains `"9"` AND `#available(macOS 27, *)` → set `decoderVersion = .version9`, else `.version8`. Default-fallback is silent. (RESEARCH §2 ⚠ notes: stamp `decoderVersionUsed` for Phase 2 sidecar — `DecodedImage.decoderVersionUsed` reserves the field.)
3. **D-23:** `DecodedImage` carries exactly three metadata structs: `CaptureMetadata` (EXIF/IPTC/XMP/GPS), `RAWTechnicalParams` (CIRAWFilter props), and `segmentationSkyMatte: CIImage?` (iPhone-only). Costly to remove fields later.
4. **D-24:** Single `decode(_:)` entry branches on UTI: RAW UTIs → CIRAWFilter path; raster UTIs (JPEG/HEIC/PNG/WebP/TIFF/PSD-flat) → `CGImageSource` → `CIImage(contentsOf:)` path. Reversible.
5. `RAW 9 no-op keys` (WWDC26/305): `colorNoiseReductionAmount`, `detailAmount`, `moireReductionAmount` are documented as no-ops under RAW 9 — `RAWTechnicalParams` reads them anyway for the RAW 8 fallback path, and Plan 06's tests assert they are not promised as functional under RAW 9.
6. **Adobe DNG (RAW-02):** No special path — Apple's DNG support is the universal fallback (UTI `public.adobe-dng`).

**acceptance_criteria:**
- Checkpoint task marked done before 01-02-02.
- The six locked decisions above are affirmed (CONTEXT.md already records user sign-off on D-21..D-24).

**action:** No file change. Gate before implementation.

## Task 01-02-03 — `RAWDecoder` actor: CIRAWFilter path (RAW 9 opt-in + fallback) + raster path + metadata extraction

**read_first:**
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-RESEARCH.md` — §2 (full `decodeRAW` sketch: probe → opt-in → build filter → read metadata → return), §6 (ImageIO metadata extraction function with ExifAux lens lookup, EXIF date parser)
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-CONTEXT.md` — D-21, D-22, D-23, D-24
- `LESSONS.md` — L001 (RAW 9 = macOS 27), L004 (segmentation matte iPhone-only)

**action:** Create `Sources/Core/RAWDecoder.swift` defining `public actor RAWDecoder`:
1. `public init()`.
2. `public func decode(_ url: URL) async throws -> DecodedImage` — the unified entry (D-24):
   - Determine UTI via `CGImageSourceCreateWithURL` + `CGImageSourceGetType`. If UTI ∈ `rawUTIs` → `decodeRAW(url)`; else → `decodeRaster(url, uti:)`.
   - On any `CocoaError`/file-read failure → throw `AppError.fileUnreadable(url.path)`.
3. `private func decodeRAW(_ url: URL) async throws -> DecodedImage` — per RESEARCH §2:
   - Probe: `CIFilter(imageURL: url, options: nil)`, read `supportedDecoderVersions` as `[String]`. If nil → throw `AppError.decodeFailed("no supportedDecoderVersions")`.
   - Build options dict: `EnableSharpening: false`, `EnableChromaticNoiseTracking: false`, `EnableVendorLensCorrection: true` (honor embedded opcodes; IOP-GEO-03 manual correction is Phase 4).
   - RAW 9 opt-in (D-22, RAW-05): `if #available(macOS 27, *), supported.contains("9") { options["decoderVersion"] = CIFilter.RawDecoders.version9 } else { options["decoderVersion"] = CIFilter.RawDecoders.version8 }`. If `CIFilter.RawDecoders.version9` is not exposed in the SDK, fall back to the string `"9"` via `kCIInputDecoderVersionKey` (RESEARCH §2 Risk #1).
   - Build real filter: `CIFilter(imageURL: url, options: options)`, read `outputImage`. If nil → throw `AppError.decodeFailed("CIRAWFilter outputImage nil")`.
   - Read `RAWTechnicalParams` via KVC (`filter.value(forKey:)`): blackLevel, whiteLevel, baselineExposure, neutralChromaticityX/Y, noiseReductionAmount, luminanceNoiseReductionAmount?, colorNoiseReductionAmount?.
   - Read `segmentationSkyMatte` via `filter.value(forKey: "semanticSegmentationSkyMatteImage") as? CIImage` (iPhone ProRAW only — L004).
   - Read `CaptureMetadata` via `Self.readCaptureMetadata(url:)`.
   - Return `DecodedImage(ciImage:, rawTech:, capture:, segmentationSkyMatte:, decoderVersionUsed: (.v9 if RAW 9 was selected else .v8), isRAW: true)`.
4. `private func decodeRaster(_ url: URL, uti: String) async throws -> DecodedImage` (RAW-04): `guard let ciImage = CIImage(contentsOf: url) else { throw AppError.decodeFailed("raster decode nil") }`. Read `CaptureMetadata` via `Self.readCaptureMetadata(url:)`. Return `DecodedImage(ciImage:, rawTech: nil, capture:, segmentationSkyMatte: nil, decoderVersionUsed: .v8, isRAW: false)`.
5. `private static let rawUTIs: Set<String>` — the full list per RESEARCH §2 (CR2/CR3, NEF/NRW, ARW/SRF, RAF, RW2, ORF, PEF, RWL, 3FR, IIQ, DNG, X3F).
6. `private static func readCaptureMetadata(url: URL) throws -> CaptureMetadata` — per RESEARCH §6: `CGImageSourceCreateWithURL` with `kCGImageSourceShouldCache: false` (critical — avoids eager decode); `CGImageSourceCopyPropertiesAtIndex(_, 0, nil)`; extract EXIF dict (`kCGImagePropertyExifDictionary`), ExifAux dict (`kCGImagePropertyExifAuxDictionary` for lensModel), TIFF dict (Make/Model), GPS dict, IPTC dict, XMP dict. Parse EXIF date string ("yyyy:MM:dd HH:mm:ss") via a `DateFormatter`. Set Optional fields; missing fields stay nil.

Use `WorkingSpace.colorSpace` (Plan 01) nowhere here directly — the CIImage color space is set when rendering to texture (Plan 03). RAWDecoder returns the CIImage as CIRAWFilter produced it.

**acceptance_criteria:**
- `Sources/Core/RAWDecoder.swift` contains `public actor RAWDecoder` and `public func decode(_ url: URL) async throws -> DecodedImage`.
- File contains `if #available(macOS 27, *)` and `supportedDecoderVersions` and `CIFilter.RawDecoders.version9` (or the string `"9"` fallback).
- File contains `kCGImageSourceShouldCache: false` (or the equivalent `false` value in the options dict).
- File contains `kCGImagePropertyExifAuxDictionary` (lens lookup) and `kCGImagePropertyGPSDictionary`.
- `rawUTIs` contains `"public.canon-cr3"`, `"com.fuji.raw-image"`, `"public.adobe-dng"`.
- Compiles under Swift 6 strict concurrency; the actor's mutable state (none expected beyond init-time) is isolated.
- A manual decode of a test CR3 (in `Resources/TestFixtures/` — Plan 06 adds fixtures) returns non-nil `ciImage`, non-nil `capture.cameraMake`, `decoderVersionUsed == .v8` on a non-RAW-9 camera or `.v9` on a RAW-9-supported camera under macOS 27.

## Task 01-02-04 — `EditorState` (@Observable @MainActor): cancellable decode + signpost + AppError bridge

**read_first:**
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-CONTEXT.md` — D-33 (MainActor UI), D-34 (async cancellable decode), D-35 (@Observable), D-31 (os.signpost)
- `.planning/phases/01-foundation-app-skeleton-capability-spikes/01-RESEARCH.md` — §7 (full EditorState pattern: Task.cancel, OSSignposter, MainActor.run, AppError bridge, Sendable RAWDecoder)

**action:** Create `Sources/Core/EditorState.swift` defining `@Observable @MainActor public final class EditorState`:
1. `public let decoder: RAWDecoder` (injected — passed in `init`).
2. `public let logger: Logger` = `Logger(subsystem: "com.kamasylvia.lightamer", category: "decode")` (D-27).
3. `public private(set) var image: DecodedImage?`
4. `public private(set) var isDecoding: Bool = false`
5. `public private(set) var decodeError: AppError?`
6. `public private(set) var loadedURL: URL?` (also drives Plan 01's empty-state switch — Plan 01's `AppState.loadedImageURL` is replaced by `EditorState.loadedURL` here; see task 01-02-05).
7. `private var decodeTask: Task<Void, Never>?`
8. `public func load(url: URL) { decodeTask?.cancel(); decodeTask = Task { [weak self] in ... } }` per RESEARCH §7:
   - Set `isDecoding = true`, clear `decodeError` (on MainActor — implicit since the class is @MainActor).
   - `let signpost = OSSignposter(subsystem: "com.kamasylvia.lightamer", category: "decode")`; `let id = signpost.beginInterval("decode", "url:\(url.lastPathComponent)")`.
   - `do { let decoded = try await decoder.decode(url); if Task.isCancelled { return }; self.image = decoded; self.loadedURL = url } catch is CancellationError { logger.info("decode cancelled: \(url.path, privacy: .public)") } catch { logger.error("decode failed: \(error.localizedDescription, privacy: .public)"); self.decodeError = AppError(error) }`.
   - `signpost.endInterval("decode", id)`; `self.isDecoding = false`.
9. `public func cancelLoad() { decodeTask?.cancel() }`.
10. `public func clearImage() { decodeTask?.cancel(); image = nil; loadedURL = nil; decodeError = nil }`.

`import os` for `Logger` and `OSSignposter`; `import Observation` for `@Observable`.

Note on Sendable: `RAWDecoder` is an actor (Sendable). `EditorState` is `@MainActor`-isolated; the `Task` closure captures `self` weakly and hops are implicit. The decode `await decoder.decode(url)` runs on the actor's executor (off MainActor) — verified by Swift 6 compiler.

**acceptance_criteria:**
- `Sources/Core/EditorState.swift` contains `@Observable`, `@MainActor`, `public final class EditorState`.
- File contains `func load(url: URL)`, `decodeTask?.cancel()`, `OSSignposter`, `beginInterval("decode"`.
- File contains `Logger(subsystem: "com.kamasylvia.lightamer", category: "decode")`.
- File contains `catch is CancellationError` and `self.decodeError = AppError(error)`.
- File contains `import os` and `import Observation`.
- Compiles under Swift 6 strict concurrency with no data-race warnings; the `Task` does not capture mutable non-Sendable state across actor boundaries.

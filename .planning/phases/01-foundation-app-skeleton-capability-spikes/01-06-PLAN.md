# Plan 06 — Test skeleton + perf instrumentation baseline (enables all Phase 1 verification; no specific REQ-ID)

> **`requirements: []`** — this plan does not map to a specific requirement ID. It builds the test infrastructure that VALIDATION.md mandates (Wave 0 + per-task verification map) and that every other Phase 1 plan's acceptance criteria depends on. It is the verification backbone for FOUND-01/02/03/05/06/07 and RAW-01/02/04/05/06.

## Goal

Stand up the test scaffolding declared in Plan 01's `project.yml` (the `LightamerTests` + `LightamerUITests` targets) and populate it with the example unit tests + UI tests + fixtures that VALIDATION.md's Wave 0 requires. Also land the `os.signpost` perf instrumentation that establishes the Phase 1 performance baseline (D-30/D-31/D-32) — most of the signpost code is already in place from Plans 02/03 (`EditorState.load` signposts the decode; `MetalContext.dispatch2D` is the natural place to signpost GPU work); this plan ensures coverage and records the baseline numbers.

Per D-28: Phase 1 ships the test SKELETON — framework ready, example tests passing, not coverage-complete. The golden-image color harness is Phase 2 (research-flagged, ROADMAP §Phase 2 success criterion #5).

## Tracer vertebra mapping

This plan does not extend the vertebra; it wraps it in verification. Every acceptance criterion in Plans 01-04 that says "verified by test" or "verified by source assertion" lands its test here. After this plan, the Phase 1 vertebra is test-covered: app launches (UI test), RAW decodes (unit), Metal pass-through is bit-exact (unit), IOPModule conforms (unit), V50Order is intact (unit), metadata reads (unit), errors bridge correctly (unit).

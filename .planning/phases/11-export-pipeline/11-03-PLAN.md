# Plan 11-03 — EXPORT 渲染腿 + 无头 ExportRenderer（W3）

> 背景：把 Phase 2 预留的 EXPORT 管线变体**材料化**（`PipeResolution.export` = typed
> stub，运行即 `.notImplemented`）：① 专用 `MTLCommandQueue`（D-15 头注预留位兑现）+
> **TaskLocal 路由**接入既有 dispatch 面（`makeCommandBuffer` 是全 dispatch 面唯一取
> 队列点——零 iop 调用点改动；`queue.priority = .low` 无公开 API 已证，低优先级落地 =
> 独立队列 + Utility QoS，裁决意图不变）；② 导出链组装 = **gamma 必剔**（管尾格式策略

> 链内，队列在 11-04 才接管调度）。resize = scale-at-entry（渲染即缩放，EXP-03）。

## 纪律（强制）

- **每任务独立提交**（Conventional Commits，只 add 相关文件）；`caffeinate -dis` 包裹一切构建；单测 `Scripts/test-direct.sh '<Class>'`（L019b）。
- **每任务边界检查 `.work/config.toml [gsd]` 开关（`auto`/`paused`）**——任务收尾 commit 后、下一任务开工前检查；`paused=true` 全链路停；`auto=false` 停等「继续」。
- **不 push**。
- **队列纪律**：`exportCommandQueue` 只能是 **NEW property**，永不重指派 `commandQueue`（D-15）；fence 挂 export 队列（R8：挂主队列 = 假绿/花屏）；iop 调用点**零改动**（TaskLocal 路由 or `queue:` 可选参，二者择一入 DECISIONS）。
- **转换恰一次不变量**：管内 colorout 一次完成 primaries+TRC 覆写目标；出口腿以同一目标 colorSpace 出 bitmap（恒等语义 + 嵌 profile 面）——双重转换 = 色偏 bug，golden 已知点抓。
- **零回归红线**：FULL/PREVIEW/THUMBNAIL 三管线行为零变化；`gamma` 在编辑链中的地位不动（只导出组装器剔除）。
- RESEARCH 未覆盖细节（TaskLocal 具体实现形态/yiyin 注入参数面裁剪/ProPhoto 覆写路径）标注**执行期决策**入 `11-03-DECISIONS.md`。

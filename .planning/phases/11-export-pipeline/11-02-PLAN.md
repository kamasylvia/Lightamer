## Tasks

### T1 ExportQuantizer 量化链（D-11-CONTEXT-7）

- **action**
  1. `ExportQuantizer.swift` 纯函数族：float32 buffer → `UInt8`（`roundf(CLAMP(v*255))`——dt `imageio.c:1403-1460` 同款 roundf 非 truncation）/`UInt16`（`roundf(CLAMP(v*65535))`；10/12-bit 在 16bpc 容器 ×1023/×4095 换算）/`Float32`（原样 + 亮度 [0,1] 钳——SDR 白以上钳位；**chroma 不裁** = 已转换到目标 primaries 后才钳，宽域目标域内值不被 sRGB 域强制）。
  2. packed layout：RGBA8 / RGBA16 / RGBAf 输出（编码器消费面）。
- **证据**：`ExportQuantizerTests` golden——roundf vs truncation 差异向量、0.5 线性已知值、CLAMP 边界（负值/超 1）、16-bit 精确值、32f 恒等（量化不弯）、中性灰恒中性。

### T2 出口转换腿 renderToEncodedBitmap

- **action**
  1. `CIContextPool` 新增姊妹函数 `renderToEncodedBitmap(_:toSpace:width:height:) -> CPU buffer`：`CIImage(mtlTexture:options:[.colorSpace: WorkingSpace.colorSpace])` → `render(toBitmap:rowBytes:bounds:format:.RGBAf, colorSpace:<目标CGColorSpace>)`（:481-501 同款；**不建纹理直出 CPU buffer**——导出无需纹理回腿）。
  2. 三纪律必抄：①跨队列 fence（:477-479）挂本 pool 的 commandQueue；②`cacheIntermediates: false`（CIRAW-4，:148）；③CPU bitmap 腿语义（:458-459 成本批注同源）。
- **证据**：单测——合成 MTLTexture（已知线性值）→ 出口 bitmap 逐点断言：中性灰恒中性（COLOR-2 不变量）+ sRGB 已知值（0.5 线性 → 187-188 显示值）+ P3/AdobeRGB/ProPhoto/Rec2020 目标角点；fence 断言（照 GUI-22 测法形态）；**ProPhoto CGColorSpace 来源执行期决策**（系统 ColorSync profile vs 构造 ROMM——DECISIONS + ICC model 断言钉）。

### T3 五原生格式 ExportEncoder + golden round-trip（EXP-01/02/04/05 元数据面）

- **action**
  1. `ExportEncoder.swift`：协议（quantized buffer + spec + 源 metadata → 输出）+ 注册表（`ExportFormatSpec → encoder` 分派单点——11-03/11-04 消费）。
  2. `ImageIOEncoders.swift`：JPEG（`kCGImageDestinationLossyCompressionQuality`）/PNG（8/16bpc，源 `bitsPerComponent` 驱动）/TIFF（8/16/32f + compression `1`=None/`5`=LZW/`8`=AdobeDeflate；**7=JPEG 不用**）/HEIC（quality；10-bit 探针 = `kCGImageDestinationEncodeBasePixelFormatRequest`）/AVIF（quality；8/10 确证 + 12-bit 探针——失败即 R1 降级文档化）。
  3. 统一面：**ICC 嵌入**走「目标 CGColorSpace 先转换进像素 + CGImage 自带 colorspace」（转换与嵌入同源杜绝错配，RESEARCH §1.2）；**EXIF round-trip** = `CGImageSourceCopyMetadataAtIndex` 读 → `kCGImageDestinationMetadata` 整体替换写（**不带 Merge**——事实 1）；**DPI** = `kCGImagePropertyDPIWidth/Height`（yiyin 语义照搬）；编辑摘要 XMP（`xmp:CreatorTool` = Lightamer+版本；rating/flag 字段面 Phase 12 预留 API 位）；XMP packet 存在性**逐格式断言**（失败格式文档化注记——R5，不后补二段式）。
- **证据**：`ExportEncoderGoldenTests` 每格式 encode→`CGImageSource` 解码 round-trip——像素（8/16 逐位；JPEG/HEIC/AVIF 有损容差带 + 已知点：中性灰/纯色四角/0.5；32f TIFF 数值恒等）+ ICC（`kCGImagePropertyProfileName`/colorspace model == 目标）+ EXIF 指定 tag round-trip + DPI + XMP 存在性矩阵；奇数尺寸探针（HEIC/AVIF 偶对齐由编码器内部处理的实证）；合成 buffer fixture 照 probe-tiff/YiyinE2ETests 先例。

### T4 WebP 编码器 + golden（EXP-02）

- **action**
  1. `WebPEncoder.swift`：`WebPEncoder.encode(rgbaPointer:format:config:originWidth:originHeight:stride:)` + `WebPEncoderConfig`（preset+quality；lossless 面——knob 名按 11-01 冒烟实况，执行期决策）；输入 = 量化后 RGBA8 buffer + stride。

- **证据**：`WebPEncoderTests`——lossless round-trip **逐位**（`WebPImageInspector` 验码流）+ lossy 容差带 + 已知点 + 奇数尺寸向量。

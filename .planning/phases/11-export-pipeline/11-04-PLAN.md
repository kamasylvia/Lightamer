## Tasks

### T1 ExportQueue actor 全件（EXP-06/07）

- **action**
  1. `ExportQueue.swift`（Core/Export）——照 SessionThumbnailProvider :154-310 逐件：`actor` 隔离 + `pending/inFlight/concurrency`（**concurrency = 1**）+ generation epoch + `cancelAll()`（bump + 清 pending + resume waiters nil；**在飞不中断**，generation 闸门弃结果）+ `cancel(jobID)`（pending 移除；in-flight 置 cancelled——渲染完成后丢弃不落盘、tmp 删净）+ `pump()` FIFO（seq 保序，无可见优先/idle delay——导出是吞吐场景，RESEARCH §4.1 明令不要）+ `execute()` 出闸 generation gate（取消的 job 出闸即弃）。
  2. job runner = `Task.detached(priority: .utility)` + `$routesToExportQueue.withValue(true)` 包裹调 11-03 `ExportRenderer`；leg 注入缝（`ExportRenderLeg`/`ExportEncodeLeg`——单测毫秒级）。
  3. `retry(jobID)` 显式重入队尾（无自动重试）；progress 快照两层（队列 `done/total`——**N variants = N jobs 计入 total**；job 层 phase）；`yieldsToEditor` 接口位保留不实现（OQ-11-8）。
  4. session 级作用域（OQ-11-3）：实例由 App 在 openSession 时重建/`cancelAll`（11-04 T3 接线）；queue 无 journal（D-11-CONTEXT-8——在飞完成或随 generation 丢弃）。
- **证据**：与契约骨架逐面核对表入 SUMMARY（状态机/快照/进度/leg 四面全兑现）。

### T2 队列语义单测全套（毫秒级，leg 注入）

- **action**：`ExportQueueTests`（照 SessionThumbnailProviderTests 先例）——①enqueue→done 顺序（FIFO seq）；②`cancel(pending)`；③`cancel(inFlight)`（结果弃/无落盘/tmp 删净断言）；④`cancelAll` + generation 闸门（旧代结果不达 waiter）；⑤`retry` 重入队尾；⑥progress `(done,total)` 快照序列（多 variant 计入 total）；⑦concurrency=1 断言（inFlight 上限探针）；⑧失败不毒化队列（failed 后续 job 照跑）；⑨session 作用域（cancelAll 后新 generation 收单）；⑩out-of-order 完成 (done,total) 正确（编码耗时差模拟）。
- **证据**：测试名清单 + 全绿 + 全套回归。

### T5 post-export actions（EXP-08，D-11-CONTEXT-6）

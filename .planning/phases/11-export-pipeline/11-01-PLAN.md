- **每任务边界检查 `.work/config.toml [gsd]` 开关（`auto`/`paused`）**——任务收尾 commit 后、下一任务开工前：`paused=true` 全链路停（在制品已 commit、报告断点）；`auto=false` 完成当前任务后停等用户「继续」。

## Tasks

### T1 ExportVariant/ExportRecipe 模型（EXP-07/EXP-03）

- **action**
  1. `ExportRecipe.swift`（Core/Export）：`ExportRecipe = [ExportVariant]`（Codable+Hashable+Sendable 值类型）；`ExportVariant = { sizing: YiyinExportSettings, scalePercent: Double?, format: ExportFormatSpec, colorSpace: ExportColorSpace, yiyin: Bool, outputTag: String? }`——`sizing` 直接复用 `YiyinExportSettings`（OQ-11-6 正主，零平行模型）；**百分比模式（EXP-03）= `scalePercent: Double?` 显式载体字段**（nil = 走 sizing 原样；设值 = 入队 entry-scale 时按源图尺寸换算 longEdge px 进同一数学，换算为纯函数、测试向量钉——checker E2 补点）；`yiyin = true` 语义 = 消费 sidecar 现有 borders/watermark 实例（EXP-05 共享配置）。
  2. `ExportFormatSpec`：`jpeg(quality) / png(bitDepth: .eight|.sixteen) / tiff(bitDepth: .eight|.sixteen|.float32, compression: .none|.lzw|.zip) / heic(quality, bitDepth: .eight|.ten) / avif(quality, bitDepth: .eight|.ten|.twelve) / webp(quality, lossless: Bool)`——位深×格式合法性校验（如 WebP 恒 8-bit，RESEARCH §1.2 能力边界）。
  3. `ExportColorSpace`：`sRGB / displayP3 / adobeRGB / proPhoto / rec2020`（EXP-04 五选）。
  4. 默认 tag 派生纯函数（D-11-CONTEXT-4）：单 variant → nil；多 variant → 尺寸或格式派生（如 `_1200`/`_webp`）。
- **证据**：`ExportRecipeTests`——Codable round-trip（含 UInt 边界）+ 校验向量表（非法位深/质量越界逐一 assert）+ tag 派生向量 + variant 正交性（同 params 多 variant 实例互不影响）。

  3. stem 特殊字符保守策略（执行期决策：替换 vs 原样——入 DECISIONS）。
- **证据**：`ExportNamerTests` 向量表（无冲突/单冲突/多冲突递增/tag 拼接/无 tag 裸名/特殊字符用例）。

### T3 ExportQueue 契约骨架（EXP-06 契约面，非实现）

- **action**
  1. `ExportQueueContract.swift`（Core/Export）：`ExportJobState` 状态机 `pending → rendering → encoding → done(URL) / failed(AppError) / cancelled`（非法迁移编译期不可达 + 运行时断言向量）；`ExportJobSnapshot`（id/imageURL/relPath/variants/seq/generation/state，Sendable 值类型）；`ExportProgress`（队列层 `done/total` + job 层 `phase(rendering|encoding)`——不承诺渲染内百分比，RESEARCH §4.1）。
  2. leg 注入缝类型签名：`ExportRenderLeg` / `ExportEncodeLeg` `@Sendable` 闭包（照 `ThumbnailDecodeLeg` 形状，SessionThumbnailProvider.swift:107-110）——队列语义单测毫秒级的测试缝。
  3. `concurrency = 1` 静态常量（D-11-CONTEXT-2 内存红线推导，头注钉：全幅 float32 工作面 ≈1.6GB@100MP）+ `yieldsToEditor` 接口位（OQ-11-8：v1 不实现，注释钉 Phase 15）。
- **证据**：状态机迁移合法性测试 + Sendable 编译期证明 + 与 SessionThumbnailProvider 契约面逐件对照表入 SUMMARY。

### T4 Swift-WebP SPM 接线 + 链接冒烟

- **action**
  1. `Project.swift`：`packages: [.package(url: "https://github.com/ainame/Swift-WebP.git", from: "0.6.0")]` + LightamerCore target 加 `.package(product: "WebP", package: "Swift-WebP")`（D-03 外部包不受限；product 名以 fetch 后实际为准，执行期决策）。
  2. `caffeinate -dis tuist fetch`——**失败预案**：`px --up` → 重跑 fetch → **`px --stop`**（一次性，日志记录走代理与否）；随后 `caffeinate -dis tuist generate && xcodebuild build` 过。

- **证据**：Project.swift diff + fetch 日志（代理路径记录）+ smoke 绿；若 strict concurrency 编译告警 → R2 预案记录入 DECISIONS（圈 actor 单编码路径，RESEARCH §2.3）。

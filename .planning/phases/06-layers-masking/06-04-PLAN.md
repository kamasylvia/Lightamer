## Tasks

### T1 parametric mask kernel（luma + JzCzhz 单 kernel）

- **action**
  1. `ParametricMask` 记录模型：`domain: luma|jzczhz`、`channels: [4 点曲线]`（per 通道 in/out 侧 4 点平滑权重——dt blendif 语义）、`boost`、后处理参数、`invert`。
  2. kernel（`blendop_mask_rgb_jzczhz` :1096-1309 + `blendop_mask_*` :426-512 直译）：从合成平面像素现算 luma/JzCzhz → 4 点曲线平滑权重 → 与 gopacity 合成；boost 因子逐式。
  3. float64 参考（BlendOpReference 扩展或独立）先行——与 6-2 同模式。
- **证据**：`ParametricMaskParityTests`——4 case（luma / JzC / hue 通道 × in/out 侧）× 6 fixture <1e-5 + compared>0 + 平场入 → 阈值内/外二元常数 mask 断言（dt 平场 probe 等价物）。

### T2 mask 后处理链（blur / feather / contrast+brightness）

- **action**
  1. blur：单通道 Deriche（GaussianBlur 工程纪律复用——buffer 双平面 L018；r32Float 适配改造点核对待）；feather：blend.c:664-710 单通道 Gaussian 直译（featherRadius 参数化；feather_in/out 双侧如 dt——执行期按 :32-39 枚举核对）。
  2. contrast/brightness：`blendop_mask_tone_curve`（:1310-1424）逐式直译（作用于 mask 平面的单通道曲线）。
  3. 后处理链顺序 = dt 组装序（_get_post_operations :305-330 逐行核——blur → feather → tone curve 顺序钉死）。
- **证据**：后处理参考剖面（手算 Gaussian/曲线剖面 vs GPU <1e-6）+ 顺序断言（两参数叠加顺序敏感性测试）。

### T3 combine 五式 kernel + MaskGroup 语义

- **action**
  1. `_combine_masks_*` 五式逐行移植（group.c:487-630）：union=MAX、intersect=MIN 夹取、difference、sum（clamp 语义核对）、exclusion——**每式含 inverted 分支**（masks.h:52-68 state 位含 INVERSE）。
  2. 多平面 reduce kernel：N 输入按序 reduce（kernel 参数数组，非原地累积——L018）；N 通常 ≤4，上界断言（>4 拒绝 + 文档）。
  3. MaskGroup 嵌套语义：items 递归（组内组）+ per-item opacity/combine/inverted。
- **证据**：`MaskCombineTests`——5 式 × 正/反逐式单测（公式直译参考对照 <1e-6）+ 合成形状 golden（两椭圆并/交/差的解析面积断言，数值级非目检）。

### T1 GUI-6 flip 面板（功能缺口，最重）

- 现状：FlipModule parity 8/8 + V50 钉死，但 inspector 无面板（「未注册面板」占位）——
  交互轮实证 flip 渲染翻转必须靠 seed 预置，用户无入口。
- 交付：`FlipPanelView`（dt flip 面板对齐：8 态方向控件——dt 用 4 组 rotate/flip 按钮 +
  EXIF auto；Lightamer 简化为 8 态 Picker 或 4×2 按钮组 + 「EXIF」项）+ Registry 面板注册 +
  catalog 增键（zh/en）+ a11y identifier（含容器 identifier 而非 label——L010）+
  PanelWiringTests 用例（切方向 = 恰 1 commit + 渲染翻转）。
- 顺带：模块行启用圆圈与此任务同文件域，若 T4 未先行则保持现状（T4 统一修）。

### T2 GUI-8 ashift 自动按钮诊断 + 修复

- 现状：自动水平/自动检测按钮点击 10s 无值变化、无 toast（交互轮实测）。
- 先诊断：按钮 action 是否接线（AshiftPanelView → InspectorState → Vision 调用链）？
  Vision 检测是否执行但结果未回写参数？还是检测本身在真实 RAW 上返回 nil？
- 修复口径：a) 接线断 → 接通；b) 检测执行但无结果 → 必须**用户可见反馈**（toast/
  状态行，按 04-03 D-T2「失败 toast 不动参数」语义），并在 DECISIONS 记录 Vision
  对该样本的行为（与 `.work/04-03/vision-field-notes.md` 互证）；c) 检测成功 →
  参数回写 + 渲染变化 + 1 commit。
- 验收：三个按钮每点击一次必有可观察效果（值变化 or toast）；PanelWiringTests
  至少钉「点击 → action 调用」一层。

### T3 GUI-7 停用模块自动启用（dt 语义）

- 现状：highpass/soften 等 disabled seed 的滑块调整不触发启用（Darktable：编辑
  停用模块参数即自动启用）。
- 交付：面板参数变更路径统一接「disabled → enabled + 1 commit」；交互轮已证的
  exposure（enabled）路径不回归。PanelWiringTests 用例：disabled 模块 setParams →
  enabled 翻转 + history 恰 1 条。
- 注意与 D-H1（连续编辑提交语义）的交互：拖动中的 live 快照不触发启用翻转风暴，
  commit 才翻转——在 DECISIONS 记录取舍。

### T4 GUI-5 启用态圆圈 + a11y 缺口

# Plan 04-03 — rotate/perspective（ashift 语义，Vision 自动检测）

## Goal

交付 IOP-GEO-02（任意角度旋转 + 透视校正 + 自动检测）。**参照物勘误（04-RESEARCH §2.2，executor 勿走错）**：dt `rotatepixels`（11.0）是 raw 域 45° 旋转数学（demosaic 后传感器网格语义），Lightamer 输入是 CIRAW 已显影域——**不移植 rotatepixels，参照 `ashift`（15.0）**：3×3 单应 forward 角点求输出 AABB（modifyROIOut）+ inverse 角点求输入 AABB（modifyROIIn）+ bilinear backward warp kernel。纯旋转是单应特例；透视 = 4 点 DLT 单应。自动检测走 **Vision framework**（`VNDetectHorizonRequest` 水平角 + `VNDetectRectanglesRequest` 透视四点，Apple 原生零依赖，D-G1 的 Vision 倾向）。

旋转非零时输出 AABB 变大出黑角——**不自动内切**，让用户用 04-02 的 crop 收（模块可组合，Lightamer 模型；dt 内嵌裁切位 cl/cr/ct/cb 保留为快捷方式）。

## Must-haves

- `AshiftParams`：rotation(±45°)/lensShiftV/lensShiftH/shear/fLength/cropFactor + 内嵌裁切 cl/cr/ct/cb（默认 0/0/1/1 全幅）——dt `ashift.c:272-290` 同构
- CPU（Double）3×3 单应合成（commitParams 时算好 → uniforms buffer，ExposureModule 模式）；4 点 DLT 求解（8×8 高斯消元 ~40 行，无依赖）
- `ashift_warp` kernel：逆单应 per-output-pixel backward 采样（bilinear），出界写 `(0,0,0,0)`——**alpha 通道首次承载语义**
- `modifyROIOut`：4 角 forward → AABB × 内嵌裁切 → floor（`ashift.c:1142-1207` 模式）；参数病态（<4px）→ 记日志 + 本件按恒等渲染（dt `piece->enabled=FALSE` 的 Lightamer 对应，不 crash）
- `modifyROIIn`：4 角 inverse → AABB + 2×插值边距 → clamp bufIn（`:1213-1289` 模式）
- Vision：水平检测按钮（angle → rotation，**符号/坐标约定 spike 探针钉死**）+ 透视自动检测（取最高 confidence 四点反解参数；失败 toast 不动参数）；输入用 `decoded.ciImage` 缩渲，**零管线平面读回**（L014 无涉但测试读回仍 drain）
- golden：**合成 float64 逆单应 + bilinear 逐式参考**（L017 路线①——warp 是空间变化算子，dt-cli 主轨不可用）；uniform 探针 + 恒等门三件套
- Vision 探针：合成水平线 θ ∈ {−8°, 0°, +5°} 检测差 < 0.2°；合成梯形 4 角还原误差 < 0.5%
- a11y：面板与 overlay 全 identifier（L010）；String Catalog zh/en

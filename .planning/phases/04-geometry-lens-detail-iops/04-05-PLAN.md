# Plan 04-05 — detail 四模块（sharpen / local contrast / highpass-soften / equalizer）

## Goal

交付 IOP-DETAIL-01..04 四个需求（5 个 op），全部踩在 Phase 3 已验证的底座上（D-G3/D-G4）：

- **sharpen（35.0，IOP-DETAIL-01）**：USM = `GaussianBlur`（Deriche IIR 双平面）+ `sharpen_mix` 软阈值 kernel；**Lab 域仅 L 通道**（经 `LabRoundTrip`——dt parity 可达的前提，勿图省事走线性 RGB）。
- **local contrast（54.0，opName `"bilat"` 对位 v50 槽，IOP-DETAIL-02）**：**复用 03-05 EIGF/guided 基建**（toneequal 的 ds 下采样 + 迭代路径直接可抄）——luma 大半径表面模糊为 base 层，`out = luma + detail·(luma − base)`；**不新写双边滤波**（D-G3 锁定）。
- **highpass/soften（34.0 / 66.0，IOP-DETAIL-03）**：USM 变体但**域不同**——highpass 是 Lab 域反相高通（display-referred 语义），soften 是 RGB 线性域 Orton 效果——dt 源码定位清楚，勿混域。
- **equalizer（27.0，IOP-DETAIL-04）**：GaussianBlur 半倍频程金字塔多频段分解 + 每带增益（**CorrectionLUT 的 band→LUT→apply 架构同构**，D-G4）；edge-aware 权重 v1 从简（checkpoint 记录与 dt eaw 的偏差）。

**D-G5 主证落在本 plan**：sharpen/local contrast 的 `modifyROIIn` 后向扩展是 ROI 协商端到端的另一半——外扩 `ceil(3σ)` 起步（GaussianBlurTests 脉冲包络校准），文档注明与 03-05 `tileHalo`（4r+65）双常数的语义分工（ROI 外扩面向「不取全图」，tileHalo 面向「分块==整幅 <1e-6」）。

**golden 策略全局**（L017 约束）：detail 全是空间变化算子 → **dt-cli EXR 主轨不可用**，走合成 float64 公式参考 + uniform 探针 + detail=0/全零参数精确恒等门；soften 平场可作 dt-cli 尝试（过双重 probe 才用）。

## Must-haves

- sharpen：`amount ∈ [0,4]`/`radius`/`threshold` 三参（dt 默认 0 中性）；σ² = (1/2.5²)·(radius·scale/iscale)²（`sharpen.c:126-180`）；`delta = L − blurL; out = L + amount·copysign(max(0,|delta|−threshold), delta)`（`sharpen.cl:145-160`）；Lab L 经 LabRoundTrip 往返、色度直通
- local contrast：`detail ∈ [−1,4]`（默认 0.25）+ sigma_s/sigma_r；detail=0 → **精确恒等门**；modifyROIIn 按 base 半径外扩；tileHalo 复用 03-05 公式（大半径 FULL 分块走 TilingPlan——toneequal 第二消费者）
- highpass：`contrast/center/radius` 三参；`invert(100−L) → h/v blur → o.x = 50 + (0.5a+0.5b−50)·contrast_scale, a/b 归零`（`highpass.c:120-265`，display-referred Lab 语义复刻）
- soften：`blur(size) → amount 混合 + saturation/brightness`（`soften.c:96-105`，RGB 线性域）；平场恒等（Orton 对平场 = 平场）
- equalizer：5-6 半倍频程带（σ 递倍）→ 带差分 → 每带增益滑块 → 重组；detail 全零 → 恒等门；与 dt eaw（6 带 edge-aware wavelet）的偏差记录
- 全部模块默认中性进链（`editingDefaultInstances`），缓存零扰动；`prewarmFunctionNames` 补新 kernel
- LabRoundTrip 为 detail 共同前置域转换（Float 版 `rec2020ToLabF/labToRec2020F` kernel 侧已有）
- PERF：每模块单帧增量 signpost 记录（预期 2-6ms@2560px Debug；03-06 优化杠杆为共同解）

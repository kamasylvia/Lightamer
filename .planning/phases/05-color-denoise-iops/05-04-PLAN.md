## Tasks

### T1 vibrance + velvia 两小件（模块 + kernel + 注册）

- **action**
  1. `vibrance`（58.0，Lab）：params v2 1 float；kernel 直译 vibrance.c:111-127（`sw=√(a²+b²)/256; out={L·(1−0.25·amt·sw), a·(1+amt·sw), b·(1+amt·sw)}`）；头注记录 dt DEPRECATED 背景与推荐去向（colorbalancergb，公式不同族）。
  2. `velvia`（57.0，RGB 线性）：params v2 strength/bias；kernel 直译 velvia.c:162-197（pmax/pmin→psat→pweight→`out[c]=clamp(c+sat·(c−0.5·othersum),0,1)`）；头注记录 clamp 本体语义 + display-referred 局限。
  3. 注册 ×2 + V50 断言 + seed（amount/strength=0 恒等 → 中性 seed enabled）。
- **证据**：V50OrderTests +2；两件 CPU 逐式参考自测 <1e-9；amount=0/strength=0 恒等断言。

### T2 colorzones：V2 splines 核对 + LUT 构建 + kernel + 模块

- **action**
  1. **CurveTools V2 核对**（plan 级决策点）：对照 dt `draw.h` `dt_draw_curve_calc_values_V2` 与已移植 curve_tools——若仅端点处理差异则复用 + 差异参数化；若实质不同则增量移植；结论入 DECISIONS。
  2. `commitParams`：3 曲线（L/C/h 各 ≤20 节点）→ 3×0x10000 float LUT（CPU 构建同 tonecurve 模式）→ MTLBuffer 上传 + 手写索引查表（256×256 伪装纹理方案**不采用**——CorrectionLUT 同款 buffer 直查）。
  3. MSL kernel `colorzones_v3`（basic.cl:3131-3185 直译）：h=atan2(b,a) 归一、C=hypot；select 查 LUT → `L'=L·2^(4·Lm)`、a'/b'=C·Cm 转 (h+hm)；hue 模式低饱和混合抑制 `blend=(1−C/128)²`；smooth/strong 两模式（v1 legacy 分支只做 strong parity 备查——结论入 DECISIONS）。
  4. 模块 60.0 注册 + V50 断言 + seed（strength=0 恒等 → 中性 seed enabled）。
- **证据**：V2 核对结论；LUT 构建自测（曲线恒等 → LUT 恒等 <1e-9）；V50OrderTests +1。
